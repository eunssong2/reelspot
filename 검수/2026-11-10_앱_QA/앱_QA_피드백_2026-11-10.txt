작성일: 2026-11-10
자료: 사용자 테스트 의견 6건 및 첨부 스크린샷 6장

※ 화면에서 확인되는 내용과 사용자가 보고한 동작을 바탕으로 정리했습니다.
   실제 앱 재현 테스트 및 영상 생성 오류의 원인 분석은 수행하지 않았습니다.

============================================================
1. 화면별 현상 및 개선 요청
============================================================

[01] 장소 정보 — 수정 기능 추가
현상
- 사용자 의견에 따르면 장소를 수정하는 기능이 없습니다.
개선 요청
- 장소 정보를 수정할 수 있도록 '수정' 버튼과 수정 기능을 추가해 주세요.

[02] 사진 업로드 — 화면 이동 및 이전 전송 내역 노출 개선
대상 화면: 파일 전송 상태
현상
- 사진 업로드 시 '파일 전송 상태' 화면으로 이동합니다.
- 해당 화면에는 파일별 완료 여부와 진행률이 표시됩니다.
- 사용자 의견에 따르면 이전에 올렸던 기록까지 함께 표시됩니다.
개선 요청
- 업로드 후 별도 전송 상태 화면으로 이동하지 않고 현재 화면을 유지해 주세요.
- 이전 업로드 기록을 다시 나열하는 대신, 이번에 업로드에 성공한 사진 수를
  간단한 메시지로 안내해 주세요.
- 안내 문구 예시: '사진 N장을 업로드했습니다.'
참고 이미지: 스크린샷/image(20261110-130138).png

[03] 사진 선택 및 미리보기 — 사진별 확대 보기
대상 화면: 사진 선택 화면 / 개별 사진 확대 화면
현상
- 첨부 화면에는 사진 2장이 선택되어 있고 하단에 '미리보기' 버튼이 있습니다.
- 사용자 의견에 따르면 '미리보기'를 누르면 선택한 사진 2장이 함께
  미리보기 대상으로 열립니다.
개선 요청
- 참고 화면처럼 각 사진의 하단 영역을 눌러 해당 사진을 개별적으로
  크게 볼 수 있도록 해 주세요.
- 확대 화면에서 자르기 등의 편집 기능을 이용할 수 있도록 해 주세요.
참고 이미지

- 사진별 확대 진입 방식 참고: 스크린샷/image(20261110-131400).png

[04] 사진 휴대폰 저장 — 별도 페이지 없이 저장
대상 화면: 기록 메뉴 → 휴대폰 저장
현상
- 기록 메뉴의 '휴대폰에 저장'을 누르면 별도의 '휴대폰 저장' 페이지로
  이동합니다.
- 이동한 페이지에서 '선택 기록 저장' 버튼을 다시 눌러야 하는 구조입니다.
개선 요청
- 별도 페이지로 이동하지 않고 현재 화면에서 바로 저장되도록 해 주세요.
- 저장 완료 후 카카오톡처럼 간단한 메시지로 결과를 안내해 주세요.
- 안내 문구 예시: '사진이 휴대폰에 저장되었습니다.'
참고 이미지
- 기록 메뉴: 스크린샷/image(20261110-131826).png
- 휴대폰 저장 페이지: 스크린샷/image(20261110-131653).png

[05] 본인 기록 메뉴 — 삭제 기능으로 단순화
대상 화면: 기록 메뉴
현상
- 현재 '본인 기록 수정·삭제' 버튼이 표시됩니다.
개선 요청
- 해당 버튼을 '삭제' 버튼으로 변경해 주세요.
- 이 메뉴에서는 수정 기능 없이 삭제 기능만 제공하면 됩니다.
- 버튼을 누르면 '삭제하시겠습니까?' 확인창을 표시해 주세요.
- '예'를 선택하면 해당 기록을 삭제하고, 취소하면 기록을 유지해 주세요.
참고 이미지: 스크린샷/image(20261110-131826).png

[06] 브이로그 영상 생성 실패
대상 화면: 영상 생성
보고된 현상
- 사용자 테스트 중 브이로그 영상 생성이 정상적으로 완료되지 않았습니다.
- 첨부 이미지 속 영상 생성 화면에는 '5 / 5 생성' 표시와 함께
  '영상을 만들지 못했어요'라는 오류 메시지가 나타납니다.
- 화면에는 편집 내용이 남아 있다는 안내와 '편집으로', '다시 생성'
  버튼이 표시됩니다.
조사 요청
- 영상 생성 실패를 재현하고 원인을 확인해 주세요.
- 실패 당시 사용한 사진·영상, 편집 설정, 기기 및 앱 버전 등 재현 조건을
  확인하고, 생성 과정의 오류 기록을 점검해 주세요.
- '다시 생성'으로 정상 완료되는지, '편집으로' 돌아갔을 때 기존 편집
  내용이 실제로 유지되는지도 확인해 주세요.
- 원인 수정 후 동일 조건에서 영상이 정상적으로 생성되는지 검증해 주세요.
현재 상태
- 생성 실패 현상은 보고되었으나, 구체적인 원인은 아직 확인되지 않았습니다.
참고 이미지: 스크린샷/image(20261110-131514).png 안의 영상 생성 오류 화면
