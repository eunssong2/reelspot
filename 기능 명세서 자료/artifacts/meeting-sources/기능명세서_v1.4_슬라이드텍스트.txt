상세 01  일정 진입과 날짜 선택
SCH-01~04 · 기존 일정 정보를 받아 화면 상태를 구성
AT THAT PLACE 기능 명세서
11
SCH-01
진입 조건과 조회
모임에서 선택한 일정 ID로 이름·기간·멤버와 날짜별 요약을 조회한다.
해당 일정의 접근 권한이 없거나 일정이 없으면 안내 후 이전 화면으로 이동한다.
SCH-02
날짜 카드 구성
시작일부터 종료일까지 날짜 카드를 구성한다. 카드에 장소 수와 사진 수를 표시한다.
저장된 날짜별 제목이 없으면 날짜 기반 제목을 사용하고, 대표 이미지가 없으면 대체한다.
SCH-03
날짜별 진입 경로
날짜 카드 선택 시 일정 ID와 선택 날짜를 장소 목록에 전달한다.
빈 날짜의 ‘장소 담기’는 같은 정보를 지도 검색에 전달한다.
SCH-04
화면 복귀와 데이터 갱신
[확정] 추가·업로드 후 해당 날짜 요약을 갱신하고 선택 날짜를 유지한다.
[제안] 최초 기본 날짜는 21장의 오늘 또는 시작일 규칙을 적용한다.

상세 02  장소 목록과 빈 상태
PLC-01~02 · 화면에 표시할 데이터와 클릭 동작
AT THAT PLACE 기능 명세서
12
PLC-01A
조회 범위와 정렬
선택한 일정과 날짜의 방문 장소만 저장된 방문 순서로 표시한다.
방문 시간이 같거나 미정이어도 방문 순서 값을 기준으로 정렬한다.
PLC-01B
카드에 표시할 정보
방문 순서, 시간, 이름, 카테고리, 주소와 제공되는 이미지를 표시한다.
시간은 없으면 ‘시간 미정’, 이미지는 없으면 카테고리 대체 이미지를 표시한다.
PLC-02A
버튼별 이동
‘사진 보기’는 방문 장소 ID를 전달해 해당 방문의 미디어를 조회한다.
‘장소 추가’는 지도 검색으로, ‘순서 편집’은 현재 날짜의 장소 편집 화면으로 이동한다.
PLC-02B
조회 상태 처리
장소 0개이면 빈 상태와 추가 버튼을 표시한다. 로딩과 실패를 빈 상태와 구분한다.
조회 실패 시 재시도 기능을 제공하며, 실패 결과로 기존 데이터를 덮어쓰지 않는다.

상세 03  검색 조건과 지도 동작
PLC-03~04 · 기존 지도 SDK와 검색 API 재사용
AT THAT PLACE 기능 명세서
13
PLC-03A
검색어 입력
장소명 또는 주소를 입력하고 검색을 실행한다. 공백만 입력한 경우 검색을 요청하지 않는다.
검색 결과는 장소 마커와 하단 목록에 동시에 반영한다.
PLC-03B
카테고리 변경
전체 / 관광지 / 맛집 / 카페 / 숙소 중 하나를 선택한다.
선택 상태를 표시하고 결과를 갱신한다. SDK 분류와의 매핑·검색어 결합 규칙은 협의한다.
PLC-04A
지도 범위 재검색
지도 이동 후 ‘이 지역 다시 검색’을 누르면 현재 지도 범위로 조회한다.
결과 없음은 해당 범위의 빈 상태로 표시하고 검색 조건 변경을 안내한다.
PLC-04B
현재 위치 및 거리
현재 위치 권한 허용 시 해당 위치로 이동한다. 거절·오류 시 검색 기능은 유지한다.
거리는 기준 위치를 확보한 경우에만 표시하며, 거리 계산 기준은 연동 시 통일한다.

상세 04  장소 선택과 저장
PLC-05~06 · 선택 상태와 저장 상태를 분리
AT THAT PLACE 기능 명세서
14
PLC-05A
마커와 목록 선택
지도 마커 또는 목록 항목 선택 시 같은 장소의 선택 상태를 표시한다.
상세 패널에 장소명, 주소, 제공되는 사진과 추가 대상 날짜를 보여준다.
PLC-05B
선택 취소와 다른 장소 선택
상세 패널을 닫으면 검색 결과로 돌아간다. 다른 장소를 선택하면 상세 내용을 교체한다.
장소 선택만으로 저장하지 않고, 추가 버튼으로 저장을 실행한다.
PLC-06A
저장 요청과 중복 방지
일정 ID, 날짜, 선택 장소 식별 정보를 전달한다. 저장 중 추가 버튼을 비활성화한다.
동일 일정·날짜·장소 중복 여부를 서버에서도 검증하고 중복이면 안내한다.
PLC-06B
완료와 실패
[확정] 성공 시 날짜별 장소와 일정 요약을 갱신하고 실패 시 선택·검색 조건을 유지한다.
[제안] 추가 완료 후 해당 날짜 목록으로 복귀한다. 연속 담기는 별도 협의한다.

[제안] 이탈 확인 및 충돌 시 선택 제공. [미정] 일괄 저장·버전 검증 API 계약.

상세 06  미디어 목록과 확대
MED-01~03 · 원본 게시물 구조는 유지
AT THAT PLACE 기능 명세서
16
MED-01
조회 대상
현재 방문 장소 ID와 사용자 접근 권한을 기준으로 미디어를 조회한다.
기본 최신순으로 표시한다. 페이지네이션 방식과 추가 정렬 옵션은 API에 맞춰 협의한다.
MED-02A
카드 생성 규칙
사진 3장이 들어 있는 게시물은 화면에서 사진 카드 3개로 표시한다.
각 카드는 원본 게시물 ID와 미디어 ID를 유지한다. 게시물을 복제하거나 분해 저장하지 않는다.
MED-02B
카드 정보와 누락 데이터
사진·작성자·시간·설명을 표시하며 사진 수 배지와 +N 표시는 제거한다.
설명이 없으면 해당 영역을 생략한다. 시간 표시 기준은 촬영 또는 업로드 중 하나로 통일한다.
MED-03
사진 확대와 영상 재생
선택한 사진을 크게 열고, 닫으면 기존 목록 위치로 돌아온다.
기존 영상 기능이 있다면 재생을 유지한다. 로딩 실패는 안내와 재시도 상태로 표시한다.

상세 07  업로드와 기존 권한
MED-04 · 기존 업로드·수정·삭제 기능을 연결
AT THAT PLACE 기능 명세서
17
MED-04A
파일 선택과 검증
업로드 버튼에서 기존 파일 선택 기능을 연다. 기존 미리보기와 선택 취소를 유지한다.
형식·크기는 기존 서버 정책에 맞추고, 선택 개수는 최대 10개로 한다.
MED-04B
업로드 대상과 진행
현재 일정·날짜·방문 장소에 파일을 연결한다. 진행 중 중복 제출을 방지한다.
업로드 권한은 서버에서 검증하며, 로그인·권한 실패는 일반 업로드 오류와 구분한다.
MED-04C
성공과 실패 반영
성공한 미디어를 목록에 반영하고 일정 요약의 사진 수를 갱신한다.
실패 파일의 재시도와 다중 파일 일부 실패 처리 방식은 기존 업로드 계약에 맞춘다.
MED-04D
수정·삭제 기능 유지
작성자·멤버 등 기존 권한 정책에 따라 수정·삭제 기능을 제공한다.
게시물 단위 삭제인지 개별 미디어 삭제인지 확인해 개별 카드 UI와 동작을 일치시킨다.

상세 08  업로드 화면(바텀시트)
MED-04 · 사진·동영상 선택, 미리보기, 업로드 실행 시안 기준
AT THAT PLACE 기능 명세서
18
진입과 화면 구성
‘사진·동영상 올리기’를 누르면 ‘지금 이 순간 남기기’ 시트가 열린다.
시트에 미리보기, 개별 삭제(X), 추가(+) 타일, 업로드 버튼을 둔다.
선택 개수와 표시
사진·동영상을 합쳐 최대 10개까지 선택하며, 가득 차면 + 타일을 막는다.
동영상은 길이(예: 0:12)를 표시하고, X로 한 개씩 뺄 수 있다.
업로드 실행과 결과
1개 이상 선택했을 때만 ‘업로드하기’를 활성화하고, 중복 제출을 막는다.
성공하면 시트를 닫고 목록·사진 수에 반영하고, 실패하면 선택을 유지해 재시도한다.
시안의 ‘방금 전 · 작성자’ 표시에 쓸 시간 기준(촬영 또는 업로드)은 협의 사항이다.
