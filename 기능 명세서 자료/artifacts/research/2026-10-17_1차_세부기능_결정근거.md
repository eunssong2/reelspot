# 1차 세부 기능 결정 근거

조사일: 2026-10-17. 구현 기준은 프로젝트 루트의 `기능명세서.md`다. 이 파일은 조사 근거와 참고 앱에서 그대로 가져오지 않은 선택을 기록한다.

## 조사 대상과 선정 범위

일정은 Google 캘린더를 기준으로 확인했다. 사진 관리·다중 선택은 Google 포토와 Samsung 갤러리, 국내 로그인·장소 검색은 카카오 서비스, 플랫폼 동작은 Android 공식 문서를 사용했다. Google Play의 Google 포토·Google 캘린더·카카오톡·카카오맵 등록 정보로 보급 규모를 확인했다. 누적 다운로드는 활성 사용자 수나 한국 내 사용 순위가 아니므로 이 자료만으로 ‘국내 1위’나 ‘모든 앱의 공통 정책’이라고 단정하지 않는다.

사용자가 직접 지정한 Android 12 이상 우선 출시·iOS 후속 개발·한국 시간 고정·유료화 후속 검토·여러 파일 일괄 처리 1차 포함을 우선 적용했다. 기존 정원·초대·원본 권한·보관 기한·종료 후 타인 기록 보존 정책은 유지했다.

Google 포토 Android의 ‘모든 필드를 일괄 편집하는 기능’이 공식적으로 동일하게 제공된다고 주장하지 않는다. 이 앱의 일괄 설명·기록일 변경은 사용자의 명시적 범위 결정에 맞춘 자체 기능이다.

## 이 앱에 맞춰 정한 초기값

다음은 다른 앱의 공통값이 아니라 이번 기능 설계를 위해 선택한 앱 자체 출시값이다. 사용량·기기·부하 검수 전에는 성능 보장 실측값으로 표현하지 않는다.

| 항목 | 선택 |
| --- | --- |
| 로그인·계정 | 카카오·Google, 같은 이메일 자동 병합 없음, 본인 재인증 후 다른 로그인 수단 연결. 이미 존재하는 두 앱 계정의 데이터 병합은 제외 |
| 기본 화면 | 월요일 시작 월 달력, 날짜 셀 3개 + 더보기, 모임은 최근 공동 활동순 |
| 반복 보호 | 기록·진행 작업·과거 발생·개별 예외 보존. 일반 미래 발생만 재계산. Google Calendar의 외부 동기화·모든 기능을 일괄 도입하지 않음 |
| 반복·기간 | 간격 1~99, 730회, 단일 활동 366일. 모든 수정도 고정 보관 기한에 영향 없음 |
| 장소 | 수기 이름 필수·주소/좌표 선택, 중복은 정규화 이름/주소/좌표 완전 일치. 이름만으로 병합하지 않음. 장소 미지정으로 되돌리기 허용 |
| 다중 선택 | 최대 120개. 일괄 수정은 같은 일정 본인 파일, 적용할 필드 명시. 일괄 삭제는 본인 파일만·파일별 결과/실패 재시도. 기기 파일 삭제 아님 |
| 정렬 안정성 | 묶음 첫 완료 시각으로 위치 고정, 내부 선택 순서, 커서 조회. 부분 완료 때 묶음을 다시 상단으로 올리지 않음 |
| 촬영·가져오기 | 기본 3초·조기 종료·무음·전후면 전환. 가져오기 영상 60초·200MB, 사진 50MB·100MP. 120개 내 촬영/가져오기 혼합 허용 |
| 저장량·개수 | 활성 참여 100모임·현재 방장 20모임 이상이면 추가 생성 제한(기존 참여 모임의 방장 역할 수신은 예외), 모임 완료 원본 합계 5GB. 장소별 사진 2장·영상 1개 같은 별도 개수 제한 없음 |
| 기한 경계 | 종료일 + 3개월의 같은 날짜 없으면 말일 보정. 보관 마지막 날 다음 00:00 한국 시각 만료. 일정 반복의 없는 날짜 건너뛰기와 별개 |
| 안내·과금 | 만료 7일/1일 전 앱 내 안내. 일정 알림 푸시·메일·결제·유료 연장은 1차 제외 |
| 삭제·운영 | 접근 차단 즉시·라이브 파일 24시간 내 정리·백업 최대 30일. 신고 최초 검토 24시간·이의 3영업일, 부재 복구는 7일 응답 대기 후 수동 검토 |

삼성 갤러리의 휴지통을 이 앱에 추가하지 않았다. 기존 즉시 조회 차단·본인 삭제·보관 만료 원칙을 유지하며 기기 원본·이미 외부로 공유된 사본은 별도로 남는다.

## 기능 결정과 별도로 남은 출시 준비

클라우드/DB/미디어 검사 공급자와 SDK 버전은 기술 설계에서 선택한다. 실제 키·배포 계정·공개 문의 연락처·법정 문구·콘텐츠 검토 인력은 운영 환경에 맞는 실값을 준비해야 한다. 제품의 기능 동작이 미정이라는 뜻은 아니며, 준비·실기기 검수 없이 출시 완료로 간주하지 않는다.
