# At that place — 동작 확인용 임시 이용약관

버전: test-2026-11-01 / 적용 시작: 2026년 11월 1일

이 문서는 가입, 모임 생성, 사진·영상 업로드와 검토 흐름을 확인하기 위한 테스트용 문서입니다. 정식 출시용 약관이 아니며, 운영 정보와 정책에는 미정 항목이 있습니다. 프로젝트 담당자와 협의한 테스트 참여자가 사용하는 것을 전제로 합니다.

## 운영 정보

- 운영자명: 미정 — 회의에서 결정
- 공개 문의 이메일·전화번호: 미정 — 회의에서 결정
- 가입 가능 연령·법정대리인 절차: 미정 — 회의에서 결정. 현재 테스트 서버에는 연령 확인 기능이 없습니다.
- 개인정보 처리·보관·백업·탈퇴 정책의 최종 확정: 미정 — 회의에서 결정

## 테스트 이용

본인 소셜 계정으로 인증하고, 표시명을 입력하며, 이 테스트 이용약관에 동의하면 가입 흐름을 시험할 수 있습니다. 개인정보 처리 안내는 별도 링크로 제공하며 필수 동의 체크 항목으로 취급하지 않습니다. 이 약관에 동의한 문서 버전과 시각은 서버 DB에 기록됩니다. 정식 문서로 교체하더라도 이 테스트 동의 기록은 자동 삭제되지 않습니다.

시험할 때는 직접 만든 테스트용 이미지·영상·문구를 사용하세요. 타인의 개인정보, 민감한 자료, 권한 없는 저작물은 올리지 마세요. 모임에 참여한 다른 테스트 사용자는 공개 승인된 기록을 보고 내려받을 수 있습니다. 이미 내려받은 사본은 서버 삭제만으로 회수되지 않습니다.

사진·영상과 일부 텍스트는 검토 대기 상태에 들어갈 수 있습니다. 서버 운영자가 내용을 확인하고 승인하면 처리 작업이 다시 진행됩니다. 테스트 도중 오류·지연·중단이 발생할 수 있으므로 중요한 원본의 보관 용도로 사용하지 마세요.

## 문의와 정식 전환

테스트 관련 문의·삭제 요청은 테스트를 안내한 프로젝트 담당자에게 기존 연락 경로로 전달하세요. 공개 이메일·전화번호와 정식 이용 조건은 회의에서 정한 뒤 문서에 반영합니다. 이 문서를 일반 사용자 출시 준비가 완료되었다는 의미로 사용하지 않습니다.
