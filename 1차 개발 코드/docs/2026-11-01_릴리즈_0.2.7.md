# Android 0.2.7 — 전체 화면 정리(PPTX) 적용

사용자 지시(2026-11-01): UI 담당 `docs/AT_THAT_PLACE_전체화면정리.pptx`(UI 브랜치 `870be87`)를 최우선으로 적용하고, 앱에 없는 기능은 만든다. 기존 기능명세 v2.3·설계 v0.3.3과 충돌하는 점은 [회의 안건](../../회의록/10월%2030일%20회의%20안건.md) 안건 1~5에 기록했다. 화면별 결과는 [UI 설계의 앱 구현 현황](../../1차%20개발%20설계서/UI/2026-11-01_UI_전체화면정리_반영.md#앱-구현-현황--027pptx-적용-후)에 있다.

## 설치 파일

- 경로: 프로젝트 최상단 `at-that-place-release.apk`(개발 폴더 `artifacts/`와 같은 파일)
- 버전 `0.2.7`, versionCode `9`, SHA-256 `8344d74dd91629bd8c9b368157f5bf62fe4f9a4c7980a493d96895ff6e1f7cd2`
- 기존 릴리즈와 같은 키로 서명했다. 0.2.4~0.2.6은 에뮬레이터 확인 중 고친 중간 빌드다.

## 서버(테스트 서버 배포 완료)

- 마이그레이션 `012_schedule_days_avatar.sql`: 일정의 날짜(일차) 테이블 `schedule_days`, 같은 모임·같은 날짜의 활성 일정 하나 검사(새 변경만 검사, 기존 겹침 자료는 유지), 프로필 사진 컬럼.
- API: `dayUpdate`·`dayCancel`·`dayDelete`(하루 제목·날짜 이동·취소·삭제), 일정 상세·달력의 `days[]`, 일정 생성·변경의 `SCHEDULE_DATE_TAKEN`, 8자리 초대 코드(기존 12자리도 사용 가능)와 `alreadyMember`(확인 횟수 미소모), `avatarPrepare`·`avatarStream`·`profilePatch`의 프로필 사진, 기록 목록의 영상 길이.
- 배포 절차: 이전 이미지 `samsun-server:before-pptx-20261101` 보존, DB 백업 `.data/backups/before-pptx-20261101.dump`, `npm run db:migrate`, `node scripts/start-server.mjs --build-only`, `MODERATION_MODE=disabled docker compose --profile app up -d --no-build api worker`. `start-server.mjs` 전체 실행은 검토 모드를 `review`로 바꾸므로 쓰지 않았다.

## 검증

- 서버 타입 검사 통과. 임시 PostgreSQL(마이그레이션·개발 문서 시드)에서 통합 테스트 67개 중 62 통과·4 생략·1 실패. 실패 1개는 이 컴퓨터에 ImageMagick이 없어 원래부터 실패하던 운영 도구 테스트다. 미디어 도구가 있는 워커 이미지에서는 75개 모두 통과(서버 작업 보고).
- 앱 타입 검사·lint 통과, 모바일 정책 테스트 15개 통과.
- 에뮬레이터(0.2.4~0.2.7): 내 모임, 모임 달력·일정 목록, 하루 일정 변경(제목·날짜 이동·하루 취소·하루 삭제), 일정 추가(같은 날 차단), 날짜별 장소(모임 전체 날짜 탭), 장소 검색(담은 장소 막기)·순서 편집, 사진별·사람별 보기·선택 다운로드, 올리기 시트(10개·중복 제외·업로드), 초대·관리(8자리 코드), 초대 확인(이미 참여 중), 함께하는 친구(카카오톡 초대·링크 복사), 마이페이지·프로필 사진 변경·되돌리기, 설정(약관 4칸·초대코드 시트), 로그인 화면.
- 확인 중 고친 것: 저장 후 같은 달력 화면이 쌓이던 문제, 하루짜리 일정 제목 표시, 링크 복사 글자 잘림, 배지 정렬, 초대 코드 입력 후 ‘링크 확인’ 문구, 영상 길이 미표시.

## 확인하지 못한 것

가입 화면 실제 표시(로그인 유지), 참여자 시점 화면과 내보내기 확인창(테스트 계정 1개), 촬영으로 올리기의 10개 제한, 실기기.
