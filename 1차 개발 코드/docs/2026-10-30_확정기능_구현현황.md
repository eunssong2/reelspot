## 이번에 보완한 연결 문제

- Google 인증을 서버 HTTPS 콜백으로 통일했다. 앱에 Client Secret을 넣지 않는다. Google 콘솔의 **웹 애플리케이션** OAuth 클라이언트와 정확한 콜백 등록이 필요하다. 참고: [Google 서버 OAuth](https://developers.google.com/identity/protocols/oauth2/web-server).
- 카카오 로그인 중 앱이 종료되어도 검증값을 SecureStore에서 복구한다. 브라우저와 복귀 화면이 동시에 응답하면 하나의 토큰 교환/세션 저장을 공유한다. 재인증 복귀를 신규 로그인으로 잘못 처리하지 않는다.
- 카카오 연결 해제는 로컬 계정 삭제와 별도로 워커가 [연결 해제 API](https://developers.kakao.com/docs/ko/kakaologin/rest-api#unlink)를 호출한다. 일시 장애는 재시도하고 인증 실패는 운영 화면의 ‘확인 필요’로 표시한다. 오래된 작업이 새로 연결된 계정을 해제하지 않으며, 완료 또는 확인 필요 전환 시 토큰을 지운다. 대기 토큰은 최대24시간 보유한다. 이 경로를 실제 개인정보 처리방침에 반영해야 한다.
- 초대는 `https://sphan0325.ddns.net/invite?token=...` 형태다. 앱 미설치자는 안내 페이지를 보고, 설치자는 앱으로 이어갈 수 있다. App Links는 [서명 인증서 지문과 웹 연결 정보](https://developer.android.com/training/app-links/configure-assetlinks)가 일치해야 한다.
- 로그인 갱신 중 서버 장애가 나면 세션을 지우지 않는다. 만료된 세션으로 로그아웃/재인증을 할 때도 갱신 후 요청한다.
- `.env`의 REST 키·Client Secret·서버 암호화 키가 Expo 공개 설정에 포함되지 않는지 확인했다.

## 실행·설정

[HTTPS 연결 안내](HTTPS_연결.md), `npm run check:runtime`, [Nginx 적용 스크립트](../deploy/install-nginx.py)를 사용한다. 스크립트는 기존 Guacamole 설정을 백업하고 앱 location만 추가하며 문법 검사를 통과한 뒤 reload한다. 개발 인증·개발 검사 상태 또는 게시 문서가 없는 상태에서는 공개 연결을 거부한다.

게시 문서는 `npm run documents:publish -- /path/to/manifest.json`으로 등록한다. 입력 예시는 [게시 manifest 예시](../deploy/documents.example.json). 내용은 검토·확정한 별도 파일을 가리켜야 하며 `{{...}}`가 남은 본문, 같은 버전의 다른 본문, 같은 항목/시행시각 중복을 거부한다. 내부 초안을 자동으로 공개하지 않는다.

`1차 개발 코드/`와 APK는 저장소 `.gitignore` 대상이다. 이번 작업은 로컬 소스·설치 파일에 반영했으며 Git commit/push와 공개 배포는 수행하지 않았다.

## 최종 검증 기록

- 실제 미디어 처리를 포함한 서버 통합 55개 통과, skip 0. 이후 문서 게시/운영 모드 전환과 모바일 로그인 복구·설치 식별자 보완에 대해 관련 23개 재검증 통과(기존 테스트와 중복 포함, 신규 문서 검사 2개 포함).
- 모바일 입력/기간/지도 문자열/HTTPS 정책 4개 통과. 서버·모바일 타입 검사, 모바일 lint, 서버·운영 웹 빌드 통과.
- Android ARM64 + x86_64 최종 APK 빌드 및 Android 15 설치·실행·초대 URI 진입 확인. API 공개 경로 미연결에 따른 오류 안내도 확인. 실제 카메라/앨범/백그라운드 전송·실 사용자 OAuth는 별도 기기 검수 필요.
- Nginx location 문법, Compose 구문 검사 통과. 실행 중 Guacamole 200 유지. 시스템 Nginx와 실제 서비스 DB는 변경하지 않음.
- APK 및 상세 검증: [검증 결과 JSON](2026-10-30_검증결과.json). 후속 코드 목록: [변경파일](2026-10-30_후속_변경파일.json). 최종 APK에는 개발 서명을 사용했으므로 Play 배포용 서명이 필요함.
