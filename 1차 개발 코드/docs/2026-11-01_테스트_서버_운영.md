| 앱 → 플랫폼 키 → 현재 JavaScript 키 → JavaScript SDK 도메인 | `https://sphan0325.ddns.net` |

| 테스트 앱을 사용한다면 앱 → 멤버 | 테스트할 카카오 계정을 멤버로 등록 |

현재 앱은 REST 브라우저 로그인을 사용한다. 이 구현의 로그인에 네이티브 SDK용 Android 키 해시나 OpenID Connect 활성화는 필요하지 않다. 서버 콜백 이후 앱이 받는 `atthatplace://oauth/kakao`는 앱 내부 복귀 주소이며 카카오 콘솔의 HTTPS 콜백을 대체하지 않는다. 카카오 OpenID Connect와 운영자용 `OPS_ISSUER`는 별개의 설정이다.

## 테스트 문서

`deploy/documents.test.json`은 `terms-service`(필수 동의)와 `privacy`(고지)를 `test-2026-11-01` 버전으로 게시한다. 운영자명·연락처·연령 정책은 미정이라고 명시한다. 테스트 동의 기록은 실제 DB에 남으며 정식 문서로 바꿔도 자동 삭제되지 않는다. 원본 정식 초안은 수정하지 않는다.

```bash
npm run documents:publish -- deploy/documents.test.json --dry-run
npm run documents:publish -- deploy/documents.test.json
```

dry-run은 승인 플래그·본문·형식·해시를 검사하고 DB를 변경하지 않는다. 이미 게시된 버전과의 충돌 검사는 실제 게시 시 수행한다. 같은 버전의 본문 변경은 거부되므로 수정할 때 새 버전·시행 시각을 쓴다. 실제 운영 서버는 `dev-` 문서를 숨기지만 이 명시적 테스트 버전은 표시한다.

정식 문서 전환 시 같은 `itemKey`로 새 버전을 게시한다. 필수 약관 버전이 바뀌면 동의가 없는 기존 사용자의 새 데이터 쓰기를 서버가 제한한다. 회의 결정 사항은 상위 `회의록/10월 30일 회의 안건.md`의 2026-11-01 추가 안건에 모았다.

## 서버 터미널에서 콘텐츠 검토

서버의 DB·파일 접근 권한이 있는 OS 계정으로 프로젝트 디렉터리에서 실행한다. 외부 운영자 HTTP API는 기존 OIDC 인증을 유지하며, 이 CLI는 별도의 공개 로그인 경로나 토큰을 만들지 않는다. 웹 운영 화면을 쓰려면 여전히 OIDC 설정이 필요하다.

```bash
npm run ops:local -- list
npm run ops:local -- show '사건-UUID'
npm run ops:local -- evidence '사건-UUID' '/tmp/검토사진.jpg'
npm run ops:local -- release '사건-UUID' 1 '합성 테스트 이미지 확인 후 승인'
npm run ops:local -- reject '사건-UUID' 1 '반려 사유'
```

`1`은 예시다. `show`에서 확인한 `case.version`을 사용한다. 사진·영상은 `evidence`로 저장한 파일을 직접 열어 확인하고, 텍스트는 `show`의 `evidenceSnapshot.proposedInput`을 확인한 뒤 승인한다. 증거는 새 파일에만 권한 0600으로 저장한다. 기존 파일 덮어쓰기는 거부한다. 검토가 끝나면 내보낸 파일은 직접 삭제한다.

목록은 자동 검사에서 생긴 미처리 사건이다. 승인하면 기존 워커가 텍스트 생성·파일 공개를 이어서 처리한다. 반려하면 해당 작업을 실패 처리한다. 가입 표시명은 검토 대상에서 제외했다. 카카오 인증·필수 약관 동의·표시명 형식 검증을 통과하면 즉시 가입된다. 판정 서비스가 없거나 응답하지 않아도 가입은 완료된다. 현재 `disabled` 설정에서는 모임 이름·일정 제목·파일도 검토 대기에 들어가지 않는다. 처리자(`local:호스트:UID:계정`), 열람·결정 사유, 전후 상태를 감사 기록에 남긴다. 버전이 오래됐거나 이미 결정한 사건의 재승인은 거부한다.

이 명령은 서버 관리자가 사용하는 수동 운영 경로다. 운영자가 검토 명령을 실행하지 않으면 콘텐츠는 계속 대기한다. 기존 웹 화면의 계정 복구·신고 전반 기능을 대체하지 않는다.
