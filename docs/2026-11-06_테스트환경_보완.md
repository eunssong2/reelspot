# 2026-11-06 테스트 환경 의존성 보완

`tests/kakao-invites.test.ts`에서 서버 모듈 import 전에 `MODERATION_MODE=development`를 명시했다. 새 `.env.example`의 review 기본값과 무관하게 이 테스트의 개발 인증·콘텐츠 준비 조건을 고정한다.

격리된 일회용 DB에서 외부 `MODERATION_MODE=review`, `RUN_INTEGRATION=1 MEDIA_TESTS=1`로 전체 검사: **100개 통과, 실패 0, 생략 0**. 서버 타입 검사도 통과했다. 실제 서버 `.env` 변경·커밋·푸시·배포는 하지 않았다.

Android15에서는 현재 backend 소스를 마운트한 격리 API·워커와 최신 앱으로 사진·동영상 저장, 가입 중단, 서버 만료 응답의 화면 처리를 실행 검증했다. 실제 카카오 인증은 기존 연결 서버를 사용하는 별도 release 변형 QA APK로 확인했고 사용자가 본인 계정임을 확인했다. 상세 환경·근거·범위는 `frontend/docs/2026-11-06_피드백_및_Android15_검수.md`에 기록했다.

실서버의 파일 복사본 검사 수치·과거 복구 신청 상태는 전달받은 외부 검토 결과이며 이번 작업에서 다시 실서버 DB를 조회해 검증하지 않았다.
