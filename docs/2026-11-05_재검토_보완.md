# 2026-11-05 재검토 피드백 보완

## 남은 확인과 적용 조건

- **실제 서버 `.env`는 변경하지 않았다.** 테스트 정책을 유지하려면 배포 시 disabled와 별도 허용값 true를 함께 설정해야 한다. 현재 설정 그대로 새 코드를 실행하면 사전 검사에서 멈추도록 의도했다. 정식 출시에서는 허용값을 false로 유지한다.
- **이전 코드에서 이미 버전 충돌이 생긴 복구 신청은 자동 수선하지 않았다.** 참여자 변동과 실제 방장 변경을 현재 버전 숫자만으로 구별할 수 없기 때문이다. 신청 스냅샷을 일괄 덮어쓰면 방장 변경 뒤에도 오래된 신청을 승인할 수 있으므로, 기존 신청은 이력 확인 후 별도 처리해야 한다. 이번 수정 이후의 입장·퇴장은 신청을 무효화하지 않는다.
- **Android 15 네이티브 화면·실제 카카오 인증은 이번에 재실행하지 않았다.** 가입 중단의 공통 뒤로가기 핸들러와 보류 초대 보존은 화면 테스트로 확인했으며 기기의 시스템 뒤로가기 전달은 추가 검수 대상이다.
- 새 `015`와 앞서 작성한 `013`·`014`는 일회용 DB에서만 검증했다. 실서버 적용·실데이터 회수 결과를 주장하지 않는다. 배포 스크립트는 설정 오류로 인한 중지를 예방하지만 마이그레이션 이후 모든 실패에 대한 자동 롤백을 보장하지 않는다.
- 앞선 검토에서 남긴 브이로그 VB05·v3.3 UI 인계, 제품 정책 결정 사항은 이번 재검토 지시 범위 밖으로 남아 있다.
