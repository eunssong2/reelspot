# 테스트 앱(데모 APK) 안내

내 담당 화면(일정 요약 · 날짜별 장소 · 장소 검색/추가 · 순서 편집 · 장소별 사진·동영상 기록)을
**예시 데이터로 눌러 볼 수 있는 Android 설치용 APK**입니다. 개발 서버나 Expo Go 없이, 로그인 없이 실행됩니다.

- 앱 이름: **AT THAT PLACE 테스트(데모)** / 패키지: `com.reelspot.app.demo` (기존 앱 `com.reelspot.app` 과 따로 설치)
- 모든 화면 위에 `TEST · 예시 데이터로 체험 중이에요` 띠가 붙어 기존 서비스 화면과 구분됩니다.
- 로그인, 일정·방 생성, 멤버 구성, 촬영·선택·업로드, 영상 병합은 **팀원 담당이라 구현하지 않았습니다.**

## 1. 설치

1. `dist\ReelSpot-Demo.apk` 를 휴대폰으로 옮깁니다(USB 복사, 카카오톡 "나에게", 구글 드라이브 등).
2. 휴대폰에서 파일을 열고 "출처를 알 수 없는 앱 설치"를 한 번 허용한 뒤 설치합니다.
3. 또는 USB 디버깅을 켠 상태에서 `adb install -r dist\ReelSpot-Demo.apk`.

기본 빌드는 `arm64-v8a`(대부분의 최신 폰)와 `x86_64`(에뮬레이터)용입니다. 32비트 폰은 빌드 시 `-Abis arm64-v8a,armeabi-v7a`.

## 2. 테스트 순서

Android 뒤로 가기 버튼: 모달(확대 보기·안내창)은 닫고, 화면은 이전 화면으로 돌아갑니다. 일정 요약(첫 화면)에서는 앱이 종료됩니다.

## 3. 구현된 것 / 팀원 연동이 필요한 것

구현(예시 데이터 + 기기 안 저장 `AsyncStorage`, 서버 없음):
- 일정 요약, DAY 탭, 장소 목록, 장소 검색·추가(중복 방지), 순서·방문 시간·메모 편집·저장, 장소별 사진·동영상 조회(확대/재생), 데모 초기화
- 방문 식별자: `일정id/일자id/장소id` (`src/demo/demoData.ts` 의 `visitKey`). 같은 장소를 다른 날짜에 담아도 기록이 섞이지 않음
- 검색: 데모 기본값은 인터넷이 필요 없는 **예시 검색**. 빌드에 카카오 지도 키를 넣으면(`-IncludeKakaoKey`) 위쪽 `실제 지도 (인터넷 필요)` 칩으로 기존 카카오 지도 검색도 쓸 수 있음(이 경우 키는 APK 안에서 추출 가능한 클라이언트 키임)

팀원 연동 지점:
- 업로드: `src/demo/uploadBridge.ts` 의 `setUploadHandler()` 로 처리 함수를 등록하면 장소 기록 화면의 "사진·동영상 올리기" 버튼이 `{tripId, itineraryId, dayId, visitId, placeId, placeName}` 와 함께 호출. 등록 전에는 안내만 표시
- 일정/모임 데이터: 지금은 `src/prototype/mock/tripData.ts` 와 `src/demo/demoData.ts` 의 예시. 실제 연동 시 `PrototypeProvider` 의 `itineraries` 를 서버 데이터로 바꾸고, 기록 조회는 `src/demo/records.ts` 의 `recordsForVisit` 를 교체
- 로그인/방/멤버: 데모 루트(`src/demo/DemoRoot.tsx`)가 건너뜀

## 4. 직접 빌드하기

```powershell
# 1) 준비물: JDK 17, Android SDK(platform-tools, platforms;android-36, build-tools;36.0.0, ndk;27.1.12297006, cmake;3.22.1)
# 2) 빌드
powershell -ExecutionPolicy Bypass -File scripts\build-demo-apk.ps1
#    경로·ABI·키 옵션:  -JavaHome ... -AndroidHome ... -Abis arm64-v8a,armeabi-v7a  -IncludeKakaoKey
```

스크립트가 프로젝트를 `C:\b\reelspot-demo` 로 복사(`.env` 제외)해서 거기서 빌드하므로 원본 프로젝트에 `android/` 폴더가 생기지 않습니다.
서명은 Expo 기본 디버그 키라 테스트 배포용입니다(스토어 배포 불가). 기존 앱과 서명이 달라도 패키지 ID 가 달라 충돌하지 않습니다.

개발 중 확인(Metro):
```powershell
$env:EXPO_PUBLIC_DEMO_MODE='1'; npx expo start -c
node scripts\check-demo-logic.mjs      # 데모 순수 로직 점검
npx tsc --noEmit                        # 타입 검사
```

예시 이미지·영상은 `node scripts\build-demo-assets.mjs <ffmpeg 경로>` 로 다시 만들 수 있습니다(`assets/demo/`, 도형으로 그린 일러스트이며 실제 사진이 아님).
