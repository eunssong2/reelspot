# 1차 개발 코드 검증 기록

최신 비인증 보완 결과·자동 검사 43개·최종 APK와 화면 근거는 [비인증 기능 검증 보고서](비인증_누락점검_및_보완.md)를 참조하세요. 아래는 최초 구현 당시의 검증 기록입니다.

검증일: 2026-10-24. 설계 v0.3 / 기능명세 v2 기준의 로컬 개발 구현입니다. 실제 외부 연동과 출시 검수 완료를 의미하지 않습니다.

사용자 요청에 따라 에뮬레이터에서 추가 실행 검증을 진행했습니다. 발견한 오류 3건과 수정 후 영상 촬영·전송·재생·저장 근거는 [에뮬레이터 추가 검증](에뮬레이터_추가검증.md)에 기록했습니다. 개발 APK는 추가 수정이 포함된 빌드로 교체했습니다.

이후 체감 지연을 줄이기 위해 에뮬레이터 자원·그래픽 구성을 조정하고, 터치 피드백과 Metro가 필요 없는 로컬 확인용 APK를 추가했습니다. [에뮬레이터 성능 조정 기록](에뮬레이터_성능조정.md)을 참고하세요.

| 확인 | 결과 | 범위 |
| --- | --- | --- |
| PostgreSQL 초기·추가 마이그레이션 | 통과 | 원본 DDL 보존, 구현용 002~005 적용, SHA256 기반 재실행 |
| 서버 TypeScript / 운영 웹 빌드 | 통과 | `npm run build` |
| Android TypeScript | 통과 | `mobile/npm run typecheck` |
| Android lint | 통과 | 오류·경고 없음 |
| Android JavaScript 번들 | 통과 | `expo export --platform android` |
| Expo Doctor | 통과 | 20/20. Android는 CNG 생성물이며 해당 정적 동기화 검사만 설정에서 제외 |
| Android 네이티브 빌드 | 통과 | 전체 JDK 21, SDK 36, minSdk 31, `assembleDebug`; WorkManager 모듈 포함 |
| 자동 검증 | 28개 통과 | 정책·PostgreSQL API·동시 요청·실파일 통합 검증. skip/fail 없음 |
| Android 12 에뮬레이터 | 확인 | 개발 로그인 → 가입 동의 → 모임/첫 일정 생성 → 달력/일정 → 카메라 권한·사진 촬영 → 후보 확인 → WorkManager 전송 → 서버 완료 → 휴대폰 저장 |
| 실제 MediaStore 저장 | 확인 | `Pictures/At that place/`에 생성된 JPEG 행과 저장 완료 화면 확인 |

자동 검증은 다음을 포함합니다.

- 모임·방장·첫 일정 원자 생성, 동일 요청 재시도, 멱등 본문 충돌.
- 비참여자 접근 및 일반 참여자의 방장 기능 거부.
- 초대 49회에서 동시 확인 시 50회까지만 허용, 방문 14개에서 동시 추가 시 15개까지만 허용.
- 사진 여섯 번째 부분 거부, 실패 자리 재사용 후 재시도 거부, 운영 제한 파일의 한도 유지와 해제.
- 청크 해시·offset·중복 PATCH·본문 없는 HEAD, 기록/작업이 있는 일정 삭제 거부.
- 기간 축소 영향 확인과 기간 밖 계획 보존, 취소 뒤 신규 업로드 차단.
- 실제 JPEG GPS 제거·촬영일 보존, MOV 전체 길이·오디오 유지·위치 제거, HEIC 호환 JPEG 생성.
- 검사 대기 중 비공개와 운영 승인 후 완료, 운영 증거의 암호화 및 앱 JWT의 증거 접근 거부.
- 타인 공동 감상과 개인 차단, 준비된 저장 작업도 나가기 후 새 파일 접근 거부.
- 정보 수정 소유권·원자성, 삭제 즉시 GET 차단과 실제 정리 후 용량 반환.
- 모임 종료 후 다른 작성자의 파일 보존, 본인 열람과 새 저장 권한 분리.
- 계정 삭제의 방장 역할 선행 조건, Unicode grapheme, 한국 시간 말일 보정, 암호화·커서 위변조.

로그와 근거는 `artifacts/`에 있습니다. `at-that-place-development.apk`는 개발 서명 APK이며 Metro와 로컬 API가 필요합니다. 출시용 APK/AAB나 스토어 서명 결과가 아닙니다.

## 남은 실제 환경 검수

- 카카오/Google 실제 앱 등록·리디렉트·인증 취소/만료·로그인 수단 연결.
- 실제 Google Maps SDK 키·Places API 키 및 장소 검색·지도 영역·거리 표시.
- 실제 콘텐츠 판정 공급자, 운영 OIDC/MFA, 운영 인력·24시간 최초 검토·이의 처리 체계.
- 실제 약관·개인정보 문서·동의 버전과 공개 문의 연락처.
- 실기기의 사진/영상 촬영 시간 오차, HDR·회전·코덱 조합, Android 13 이상 권한·알림, 강제 종료·네트워크 변경의 장시간 반복 검수.
- 120개 혼합 파일과 기준 실기기의 p95 목록·영상 성능. 목표 달성을 실측한 결과는 아직 없음.
- 운영 저장소·백업·복원·삭제 상태 재적용, 서비스 계정 최소 권한, 배포 서명과 App Links 등록.
- 모바일 전이 의존성의 보안 권고가 남아 있음. `artifacts/mobile-audit.json` 참고. SDK를 강제 다운그레이드하거나 비호환 major로 바꾸지 않았으며 출시 전 호환 패치 검토가 필요함.

서버 파일·권한·기한 처리는 실제 로컬 구현이며, 개발용 로그인과 판정 대역은 별도 모드입니다. 운영 모드에서는 개발 대역을 허용하지 않습니다.
