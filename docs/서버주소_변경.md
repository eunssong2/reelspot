# 서버 주소 변경 · 2026-10-24

요청한 API 주소는 `http://sphan0325.ddns.net:8081`입니다.

서버 `.env`의 `HOST=0.0.0.0`, `PORT=8081`, `PUBLIC_URL=http://sphan0325.ddns.net:8081`을 설정하고 API를 재시작했습니다. 기존 DB와 비밀값은 유지했습니다. 미디어 워커도 변경한 환경으로 다시 실행했습니다. DB는 계속 PC 내부의 55432 포트를 사용합니다.

앱의 `mobile/.env`, `.env.example`, API 기본값과 운영 웹의 API 기본값을 같은 도메인으로 바꿨습니다. 약관·개인정보 문서의 URL도 새 주소로 반환합니다. 앱의 업로드 작업은 공통 API 주소를 사용합니다.

서버는 개발 모드이며, 기존 개발용 인증·판정 설정을 사용합니다. 확인용 APK는 HTTP 접속을 허용하고 JavaScript를 포함하므로 Metro가 필요 없습니다.

## 확인

- PC와 Android 15 에뮬레이터에서 도메인 `/health` 응답 HTTP 200.
- 도메인의 `/v1/app-config`, `/openapi.json`, `/v1/consent-documents` 응답 HTTP 200.
- 동의 문서 응답의 URL이 새 도메인인지 확인하고 각 문서 HTTP 200.
- 새 주소로 기존 테스트 계정 로그인 및 기존 모임 2개 조회 성공.
- 기존 사진 JPEG와 영상 MP4에 새 도메인으로 Range 요청, 각각 HTTP 206 및 1,024바이트 응답 확인.
- 운영 웹 `http://localhost:5173`의 CORS 사전 요청 HTTP 204.
- 서버 타입 검사·빌드, 기본 테스트 5개 통과. 기본 실행에서 DB·미디어 통합 테스트 3개는 제외되며 이번 주소 변경에서는 다시 실행하지 않았습니다.
- 앱 타입 검사·린트 통과.
- x86_64·ARM64를 포함한 APK 빌드 성공(10분 5초). APK 내부 JavaScript의 새 API 주소와 이전 주소 제거를 확인했습니다. Android 12 이상용이며, 최상단 `at-that-place-preview.apk`를 교체했습니다.
- Android 15 에뮬레이터에 기존 데이터를 보존해 업데이트 설치하고 앱을 완전히 다시 실행했습니다. Metro 없이 기존 모임 목록·모임의 일정·일정의 장소가 표시되는 것을 확인했습니다. 화면 XML과 스크린샷, APK SHA256은 `artifacts/domain-connection/`에 있습니다.

HTTP 확인 결과는 `artifacts/domain-connection/`에 저장했습니다. APK 빌드 로그는 `artifacts/domain-preview-build.log`입니다. 과거 에뮬레이터 성능·미디어 검증 문서의 이전 주소는 당시 측정 환경을 나타냅니다.

## 다시 실행

코드 폴더에서 `npm run dev`, `docker compose --profile worker up -d db worker`를 실행합니다. APK 재생성은 `mobile/`에서 `npm run preview:android -- --abi=x86_64,arm64-v8a`입니다. 새 주소를 적용한 APK는 프로젝트 최상단의 `at-that-place-preview.apk`로 복사됩니다.
