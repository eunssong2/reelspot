잔여 구현·고객 추가 요청 검증

2026-11-06 · Google 로그인 제외 · 콘텐츠 자동 판정 일시 중지

구현 잔여와 C01~C13의 구체적인 기능 변경을 반영하고, 수정된 격리 서버와 최신 Android 15 앱으로 관련 동작을 확인했다. 실제 서버 배포나 모든 기능명세 TC의 전수 통과를 뜻하지 않는다. Google 지도 테스트/전환, 실기기·TalkBack, 최신 수정본의 실제 카카오 재인증은 완료하지 않았다.

사용자 요청에 따라 콘텐츠 자동 판정은 꺼져 있다. 실제 서버 /health도 moderation=disabled이며 기존 .env는 변경하지 않았다. Google 로그인은 이번 구현/검증에서 제외한다. 변경 소스는 미커밋이며 푸시·배포하지 않았다.

후속 수정: 초대 취소·브이로그 재시도·카카오 오류 재검증. 이 보고서 이후 보완 및 검증은 후속 보고서를 기준으로 확인한다.

적용 기준

  • 사용자가 C01~C13 추가 요청과 서버 FFmpeg 생성·원본 음성 유지·BGM 미추가·임시 보관 후 기기 저장을 선택했다.
  • 정원은 기존 모임 포함 15명. 초대는 168시간/성공 미리보기 50회 소진 후 자동 발급한다. 이전 유효 코드와 수동 취소 정책을 유지하며 50번째 미리보기 후 새 참여 거부 규칙도 유지한다.
  • 렌더 결과 24시간·사용자당 동시 대기/진행 2개는 이번 구현의 운영 기본값이다. 기존 브이로그 50개/180초 등은 현행 제안 수치를 적용했다.
  • VB05의 40dp 미리보기 방식은 회의 검토 대상으로 남긴다. Gboard 확인은 최종 UX 승인이나 실기기 검수를 대체하지 않는다.

발견 후 수정한 결함

  • 카메라: Activity 재생성 후 보유한 launcher의 수명주기와 UI 스레드 문제를 실제 기기에서 재현해 보완했다.
  • MP4: LocationInformation GPS 태그가 파생본에 남아 업로드가 거부되던 경로를 고쳤다.
  • 연속 전환: 컨테이너/음성은 4초지만 영상 트랙이 2.5초에서 끝나던 오류를 수정했다. 이제 각 영상·음성 트랙 길이와 마지막 프레임을 직접 검사한다. 초기 matrix.log만으로 통과 판정하지 않는다.
  • 장소 검색: 늦게 실패한 이전 검색이 새 검색 성공 결과를 오류로 덮는 경우를 막았다.
  • 추가 터치 영역: 기기 확인 중 발견한 순서 버튼 46dp, 영상 구간 44dp, 지도 확대/축소 영역도 보완했다.

미확인·보류·적용 전

  • Google 로그인: 사용자 요청으로 제외. Google 지도 테스트/전환도 공급자 설정이 없어 미적용이며 카카오를 사용한다. 원 요청의 “테스트 때 Google?” 문구를 완료 처리하지 않는다.
  • 실제 카카오: 기존 릴리즈에서 사용자 인증한 이력은 있으나 이번 수정본은 격리 개발 인증으로 검증했다. 실제 공급자 장애/취소/콜백 전 경로는 재검증하지 않았다.
  • 기기·접근성: 실기기, TalkBack 실제 낭독, 모든 화면 크기·입력기·글꼴 크기의 48dp 전수 검수, iOS, 릴리즈 성능/메모리 부족/저장공간 부족의 전 조합은 미확인이다.
  • 브이로그: 편집 미리보기는 동영상 커버 기반이다. 최종 영상은 실제 움직임·음성을 포함하므로 두 화면의 픽셀 단위 동일성을 주장하지 않는다. Q19 원본 기획과 VB05 최종 UX 검토는 남아 있다.
  • 운영 반영: 신규 migration 016/017과 FFmpeg/font 의존성이 들어간 서버 이미지, 최신 앱을 함께 배포해야 한다. 이번에는 배포하지 않았다. 콘텐츠 판정 서비스는 사용자 요청으로 연결하지 않는다.
  • 이번 결과는 변경 기능의 회귀 검증이다. 과거 보고서의 전체 F01~F30 검수표에서 수행하지 않은 TC를 일괄 통과로 바꾸지 않는다.
