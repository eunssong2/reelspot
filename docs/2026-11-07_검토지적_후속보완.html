검토 지적 후속 보완

2026-11-07 · 브이로그 중단·재생성 경쟁, 로그인 복귀, 오래된 초대 표시

두 결함과 초대 표시 지적을 수용해 수정했다. 이전 보고서의 “새 초대 만들기에서만 발급”은 검수한 경로에 한정된 설명이며 전체 발급 정책으로 읽히는 표현을 정정했다. 커밋·푸시·배포·운영 .env 변경은 하지 않았다.

수정

항목수정과 확인
브이로그 작업 소유권새 요청이 시작되면 await 전에 작업 제어권을 이전한다. 늦은 이전 요청은 새 요청의 서버 작업을 취소하거나 작업 목록에서 삭제하지 않는다. 생성 API 응답을 기다리는 중에도 같은 생성 약속을 공유한다. 취소를 이미 시작한 작업은 재사용하지 않는다.
다운로드 파일요청마다 다른 파일 이름을 사용한다. 이전 다운로드의 늦은 완료·오류 정리는 자기 파일에만 적용된다. 다운로드 중 중단·재생성 회귀 테스트는 새 결과 파일이 남고 저장되는지 검사한다.
중단 처리후속 요청이 없으면 기존 서버 작업 취소를 유지한다. 현재 GenerateStep 요청이 cancelled로 끝나도 스피너에 남지 않고 중단 안내와 재시도를 표시한다.
로그인 복귀finish의 확정 오류 응답은 보류 인증 상태를 지우고 로그인 복귀를 주 버튼으로 표시한다. 통신 실패로 보류 상태가 남아 있거나 finish 성공 토큰이 보존된 exchange 실패만 재시도를 허용한다. 실패 뒤 “인증 결과를 확인하고 있어요” 문구를 숨긴다.
오래된 초대다른 기기에서 취소된 초대를 공유·복사할 때 대체 코드를 발급받으면 목록을 다시 불러온 뒤 복사한다. 새 화면 코드와 실제 복사 값이 일치하도록 자동 테스트하고, 기기에서 새 코드 표시도 확인했다.
