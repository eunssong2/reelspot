# 2026-11-04 화면 흐름 피드백 검토 및 보완

> 이 보고와 검증 JSON은 추가 피드백 반영 전 스냅샷입니다. 기본 이미지 복원·초안 복구·시간 충돌·후보 보관 정책은 [후속 보완](2026-11-04_추가피드백_보완.md)을 참고하세요.

기준: `docs@ded2a6c7e2420b5959fd18d05ede38943f18c781`, 기능명세 v3.2, 설계 v0.5.0, 프로토타입 `9f64b5e88d7d3e663726975f2408b181f13a0413`. 문서·프로토타입 원천은 수정하지 않았다. backend와 frontend의 작업 사본에 반영했으며 커밋·배포하지 않았다.

검토 결과, 지적한 7가지 경로의 문제는 코드에서 확인됐다. 특히 파일별 장소·날짜를 현재 화면 값으로 덮어쓰는 문제는 앞선 구현 변경에서 생긴 회귀다. 기존 자동 검사만으로 화면 흐름과 명세 전체의 일치를 보증할 수 없다는 지적도 타당하다. 아래 보완과 검증 한계가 이전 [구현 점검](2026-11-04_명세_v3.2_구현점검.md)보다 우선한다. 이전 검증 JSON은 수정 전 스냅샷이다.

## 수정 내용

D11과 D12는 저장 시점이 다르다. **타임라인의 시간 변경(D11)은 즉시 저장**하고, **순서 편집(D12)은 시간·순서·제목을 편집한 뒤 변경 저장**한다. `/plan`에도 같은 휠을 사용하지만 D12의 일괄 저장은 유지했다.

기존 후보 복구는 서버 제출을 자동으로 수행하지 않는다. 삭제·이동된 장소로 자동 재지정하지 않으며 원래 장소를 사용할 수 없으면 안내하고 후보를 보존한다. 기존 후보와 현재 후보를 합쳐 10개를 넘으면 현재 후보를 먼저 정리하도록 안내한다.

## 추가 보완 및 호환성

- 접수되지 않은 후보가 남았는데 `fileErrors`가 비어 있어도 복구 안내가 있는 오류를 표시한다. 접수 결과가 불명확한 후보는 보존한다.
- 영상 끝 경계 검사에 `1e-9`초의 부동소수점 오차 허용을 추가했다. 27.56초 원본/10.252초 분할 사용 사례와 4,539개의 끝 경계 조합을 검사했고, 실제 0.001초 초과는 계속 거부한다.
- 서버 구현 계약에서 `view=by_time`을 이전 APK용 별칭으로 허용하고 내부에서 `by_photo`로 정규화한다. 통합 검사에서 두 응답이 같은지 확인했다. 잘못된 enum은 계속 400으로 거부한다. 별칭 제거는 이전 APK 지원 종료 후 별도 변경으로 다룬다.
- 더 이상 읽지 않는 `PLACES_PROVIDER`, `GOOGLE_PLACES_API_KEY`를 서버 환경 예시와 안내에서 제거했다. Google 로그인·지도 설정과는 별개다.
- 기존 Google 장소 데이터는 삭제하지 않았다. 과거 방문 참조를 유지해야 한다. 리뷰에서 언급한 테스트 DB의 3건이라는 수치는 이번 검토에서 별도로 재조회하지 않았고 실제 화면도 확인하지 않았다.

`by_time` 호환은 해당 조회 회귀의 보완이며, 이전 APK의 모든 기능에 대한 호환 보증은 아니다. 서버 반영 시 마이그레이션 `013_spec_v32.sql`이 필요하다. 새 앱은 새 서버의 groupDays/vlog-sources 등의 계약에 의존하므로 앱·서버 배포 버전을 함께 관리한다. 이 작업에서는 운영 마이그레이션이나 서버 재시작을 하지 않았다.

### 재실행

앱: `npm test`, `npm run test:flows`, `npm run typecheck`, `npm run lint`, `npm run export`, `npm run preview:android -- --abi=x86_64`.

서버: 별도 임시 PostgreSQL DB에 001~013과 개발 seed를 적용한 뒤 `npm run typecheck`, `npm run build`, `npm run test:integration`을 실행했다. 통합 검사는 현재 소스를 마운트한 미디어 도구 이미지에서 실행했으며 아래 값을 명시했다. 테스트 서버 DB를 재사용하지 않는다.

```text
DATABASE_URL=postgres://<테스트 계정>:<테스트 암호>@127.0.0.1:<임시 포트>/<임시 DB>
OBJECT_ROOT=<임시 파일 저장소의 절대경로>
NODE_ENV=development
AUTH_MODE=development
OPS_MODE=development
MODERATION_MODE=development
MEDIA_TESTS=1
```

검증 소스·로그·APK 해시는 [후속 검증 기록](2026-11-04_화면흐름_검증.json)에 남겼다. 로그 해시는 실행 당시 로컬 `/tmp/atp-feedback-*.log`의 값이며, 로그 본문은 저장소에 포함하지 않는다. 빌드 APK는 frontend의 `artifacts/at-that-place-preview.apk`에 있다. 기존 실서비스 컨테이너는 변경하지 않았다.
