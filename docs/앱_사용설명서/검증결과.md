# 에뮬레이터 검증 결과 · 2026-10-30

이번 결과는 Android 15(API 35, x86_64) 에뮬레이터에서 실제 화면을 터치하고 입력해 확인한 결과입니다. 전체 기능·실기기·출시 검증 완료를 의미하지 않습니다.

## 환경과 범위

- 기존 공개 APK: `https://sphan0325.ddns.net`. 공개 `/health`·앱 설정 경로는 Nginx의 503 준비 응답이며, Guacamole은 200입니다.
- 기능 검증 APK: 같은 앱 소스에 테스트용 HTTPS 주소와 localhost 전용 인증서 신뢰 설정만 임시 적용했습니다. Android 평문 통신은 허용하지 않았습니다. 이 APK는 배포용으로 제공하지 않습니다.
- HTTPS 테스트 서버: PC의 loopback에만 연결하고 ADB reverse로 에뮬레이터에서 접근했습니다. 시스템 Nginx와 실제 운영 DB는 변경하지 않았습니다.
- 별도 임시 PostgreSQL·미디어 워커를 사용했습니다. 로그인·콘텐츠 판정은 개발 모드입니다. 실제 외부 Google 인증을 사용한 것이 아닙니다.
- 두 테스트 계정 Mina(방장), Jin(일반 참여자), 모임 Weekend, 일정 Autumn picnic을 사용했습니다. 카메라는 에뮬레이터 가상 입력입니다.
- 일부 화면 전환은 앱 딥링크를 사용했습니다. 생성·등록·동의·초대·전송·저장·문의 동작은 실제 UI로 실행하고 API·MediaStore 결과로 교차 확인했습니다.

## 발견한 문제와 수정

1. Nginx 준비 응답이 앱에 `SERVICE_NOT_READY`라는 코드로 표시됐습니다. `mobile/src/lib/api.ts`에 ‘서비스 연결을 준비하고 있습니다. 잠시 후 다시 시도해 주세요.’라는 안내를 추가했습니다.
2. 테스트 API 주소만 바뀌었을 때 Gradle이 이전 JavaScript 번들을 재사용했습니다. 실제 공개용 APK 재설치에서 연결 오류를 확인했습니다. `mobile/scripts/build-preview.mjs`가 `createBundleReleaseJsAndAssets --rerun`을 먼저 수행하도록 변경해 환경변수가 새 번들에 반영되게 했습니다.

최종 공개 APK를 다시 설치해 한국어 준비 안내를 확인했습니다. 번들에서 `https://sphan0325.ddns.net`을 확인했고, 테스트 API 주소와 테스트 인증서 리소스가 없는 것도 확인했습니다. [최종 화면](화면/40_공개APK_준비안내.png)과 [최종확인.json](검증자료/최종확인.json)에 결과를 기록했습니다. 테스트용 신뢰 인증서·네트워크 설정은 원본 Android 소스에서 복원했으며, 배포 APK에 포함하지 않습니다.

모바일 TypeScript 검사와 ESLint 검사를 통과했습니다. 빌드 스크립트의 Node 구문 검사도 통과했습니다. 이번 변경은 서버 업무 로직을 바꾸지 않았으며, 과거 통합 테스트 숫자를 이번 실행 결과로 합산하지 않았습니다.

## 아직 확인하지 않은 범위

- 실제 카카오 로그인 완료, 토큰 교환, 공개 HTTPS 콜백에서 앱 복귀. 공개 API 연결이 준비 모드여서 이 흐름은 완료할 수 없습니다.
- Google 로그인. 사용자 요청대로 보류했습니다.
- 실제 콘텐츠 검사 업체·운영자 검토, 실제 운영 약관 게시, 계정 삭제와 카카오 연결 해제.
- 카카오 장소 검색 결과 선택, 위치 권한 거부·실제 GPS 정확도, 전체 지도 무료 한도 소진 시 동작.
- 실제 휴대폰 카메라 품질·음성·회전·HDR, 통화 중 중단, 장시간 백그라운드 전송, 저장 공간 부족, 사진 선택기 전체 형식 조합.
- 방장 이전·강제 퇴장·모임 종료·삭제·신고 판정과 모든 충돌·오류 조합.
- 이번 사진의 촬영 시각 메타데이터는 없어서 ‘촬영 시각 정보 없음’으로 표시됐습니다. 모든 단말의 사진 촬영 시각 보존을 검증한 것은 아닙니다. 영상에는 촬영 시각이 표시됐습니다.

테스트에서 통과한 기능과 실제 공개 서비스의 가동 상태는 별개입니다. 공개 서버는 여전히 준비 모드이며, 이 설명서의 테스트 계정·예시 문서·localhost 초대 주소를 사용자에게 배포하면 안 됩니다.

## 검증 후 정리

임시 에뮬레이터와 테스트 API·미디어 워커를 종료하고, 임시 DB 컨테이너와 테스트 TLS 개인키를 제거했습니다. 기존 Guacamole 컨테이너와 Nginx 설정은 유지했습니다. 공개 APK는 저장소 루트와 `artifacts/` 양쪽에 같은 파일로 갱신했습니다.
