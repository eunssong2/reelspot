## 자동 검사와 빌드

| 실행 | 결과 | 근거 |
| --- | --- | --- |

| 모바일 타입 검사·lint | 통과, 오류/경고 0 | `artifacts/non-auth-mobile-types.log`, `non-auth-mobile-lint.log` |
| 정책·실제 PostgreSQL·실파일 통합 검사 | **42개 통과, 실패/skip 0** | `artifacts/non-auth-full-tests.log` |

통합 검사는 워커 이미지의 FFmpeg·ExifTool·ImageMagick·HEIC 지원 환경에서 실행했습니다. 테스트 중 상시 워커는 잠시 정지하고 완료 후 최신 이미지로 재시작했습니다. 개발 로그인 대역으로 만든 별도 UUID 테스트 계정/모임을 사용했으며 기존 `test`·`DemoTrip` 모임은 보존했습니다. Google 검사는 모의 HTTP 응답이며 외부 Google 서버 성공으로 보고하지 않습니다. 초기 실패 로그(`non-auth-integration-host.log`)는 수정 후 위 전체 통과 로그로 대체됩니다.

실행 방법:

```bash
npm run contracts
npm run typecheck
npm run build
npm run test:mobile-policy
cd mobile
npm run typecheck
npm run lint
npm run preview:android -- --abi=x86_64,arm64-v8a
```

FFmpeg 통합 검사는 코드 폴더에서 상시 워커를 정지한 상태로 `docker compose run --rm -e MEDIA_TESTS=1 worker npm run test:integration`을 실행하고, 이후 `docker compose --profile worker up -d worker`로 재시작합니다. `--skip-prebuild`는 네이티브 설정을 이미 생성했고 JS만 바뀐 경우 빌드 시간을 줄이는 선택 옵션입니다.
