## 디자인과 다르게 구현한 부분

색·글자는 팀 프로토타입 토큰(`src/prototype/styles/tokens.ts`: 흰 배경 + 회색 면 + 코랄, 그림자 없음)을 썼습니다. Stitch의 푸른 배경(`#f8f9ff`)·흰 카드 그림자·Plus Jakarta Sans 글꼴·Material 아이콘은 쓰지 않고, 아이콘은 기존 프로토타입처럼 기호·이모지로 대신했습니다. 배치와 구성은 디자인을 따랐고, 아래는 **명세와 맞지 않아 바꾼 것**입니다.

## 프로토타입 확인 방법

`/prototype`을 열면 로그인부터 시작합니다. 서버 없이 예시 데이터로 동작하고 새로고침하면 처음 상태로 돌아갑니다.

- 처음 로그인한 수단은 신규 가입(UI02)으로, 같은 실행에서 다시 로그인하면 기존 사용자로 처리됩니다.
- 로그인 화면의 `예시: 받은 초대 링크로 열어 보기`로 로그인 전 초대 흐름을 볼 수 있습니다.
- 내 모임 맨 아래 `예시: 로그아웃하고 처음부터 보기`로 처음으로 돌아갑니다.
- 예시 초대 코드: `Q7KM2P8R`(주말 산책 모임, 사용 가능) · `C4MPUS27`(대학 동기 모임) · `H5TW8C2N`(소진) · `B2RD7NW4`(만료) · `Z9PL4HC6`(취소) · `F4LL10AB`(정원 초과 모임) · `CLSDGRP2`(종료된 모임) · `BLKDRD45`(재참여 차단)
- 로그인 상태는 기기에 저장돼 새로고침해도 이어집니다(세션 복원 스플래시). 모임·일정·초대 예시 데이터는 새로고침하면 처음으로 돌아갑니다.
- 설정 탭의 `로그아웃`, `초대코드 입력`도 이 흐름에 연결돼 있습니다.

### 예시 상황 패널 (🧪)

화면 오른쪽 가장자리의 작은 🧪 손잡이를 누르면 명세 8장의 오류·로딩 상태를 바로 띄울 수 있습니다. 실제 앱과 테스트 APK에는 들어가지 않습니다.

| 묶음 | 상황 | 확인할 화면 |
|---|---|---|
| 공통 | 인터넷 끊김 · 느린 응답 · 조회 실패 | 모든 화면의 오프라인 안내, 로딩 표시, 모임 목록·달력·초대·동의 문서 조회 실패 |
| 로그인 | 인증 창 닫음 · 인증 실패 · 로그인 서비스 장애 | UI01 오류 안내 |
| 입력·저장 | 공개 전 검사 거부 | UI02 표시명, UI04 모임 이름·제목, UI06 제목 |
| | 동의 문서 변경 (한 번) | UI02 제출 시 개인정보 문서 새 버전 → 다시 확인 |
| | 응답 유실 (한 번) | UI04 "저장 결과를 확인 중이에요" → 같은 요청 결과 확인(모임이 두 번 생기지 않음) |
| | 동시 수정 충돌 (한 번) | UI06 저장 시 최신 내용 표시 → 다시 적용/최신으로 바꾸기, UI23 초대 취소 |
| | 모임 100개 · 방장 20개 한도 | UI04 만들기, UI24 참여 |

`앱 다시 시작`을 누르면 세션 복원 스플래시부터 다시 봅니다(인터넷 끊김을 켜 두면 스플래시의 오프라인 안내).

### 아직 넣지 않은 것

- 모임 목록 30개 단위 이어 불러오기: 예시 모임이 7개라 화면에서 확인할 수 없어 넣지 않았습니다.
- 실제 초대 링크 앱 열기(Android 앱 링크): 프로토타입은 지금 실행 중인 주소(`…/prototype/invite?code=…`)로 링크를 만들어, 복사한 링크를 열면 초대 확인이 뜹니다.
- `내 기록` 탭(UI22)은 다른 담당 화면이라 안내만 띄웁니다.
