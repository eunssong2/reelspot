# Android 0.2.1 테스트 릴리즈

2026-11-01 사용자 요청에 따라 프로젝트 최상단의 기존 preview/release APK 2개를 삭제하고 최신 작업 소스로 릴리즈 APK를 재빌드했다. 누적 앱·서버·기능명세·설계·회의 문서 변경을 `feature/mobile-app` 브랜치에 함께 반영한다.

## 설치 파일

- 경로: 프로젝트 최상단 `at-that-place-release.apk`
- 앱 버전: `0.2.1`, Android versionCode: `3`
- 패키지: `kr.atthatplace.app`
- Android 12(API 31) 이상, ARM64 / x86_64
- 크기: 120,296,316바이트(약 115 MiB)
- SHA-256: `1702d13408646c8875619e41ddcc2f0b0dddac46078c50a75f509f7235861243`

0.2.0 릴리즈와 같은 전용 키로 서명했다. 기존 릴리즈에는 업데이트 설치할 수 있다. debug 키로 서명한 preview와는 서명이 다르다. APK는 기존 `.gitignore`에 따라 Git 커밋에 포함하지 않으며, 소스와 이 검증 기록을 업로드한다. 개발 폴더의 `artifacts/at-that-place-release.apk`는 최상단 파일과 동일하다.

## 적용 상태

고객 UI 반영 내역은 [0.2.0 기록](2026-10-30_릴리즈_빌드_검증.md)을 따른다. 이번 빌드는 최신 소스를 다시 묶고 버전·versionCode를 올렸다. API 주소는 `https://sphan0325.ddns.net`이다.

Nginx 외부 연결, 테스트 약관·개인정보 안내 게시, 서버 터미널 수동 검토 기능을 적용했다. 가입은 인증·약관 동의·표시명 형식 확인 후 즉시 완료하도록 서버를 수정했다. 이후 테스트 서버의 사전 운영 검토도 모두 해제하여 모임·일정·장소·사진·영상·커버를 승인 대기 없이 테스트할 수 있다. [테스트 서버 운영 안내](2026-11-01_테스트_서버_운영.md)에 처리 방법과 미정 정책을 기록했다. 실제 카카오 계정 로그인 완료·실기기 복귀 검증은 아직 남아 있다.

## 검증

- `npm run release:android`: 성공. JavaScript 재번들, 두 ABI 빌드, 릴리즈 서명 검증 완료.
- 모바일·서버 타입 검사, 모바일 lint 통과. 모바일 정책 테스트 8개 통과.
- 앞선 서버 적용 작업에서 분리 DB·실파일 통합 테스트 60개 통과. 이번 버전 번호 변경 후 이 테스트를 다시 실행한 것은 아니다.
- APK의 패키지·버전·최소 SDK·ABI, 디버깅 비활성·평문 통신 비활성 확인.
- 기존 릴리즈 인증서와 일치하며 외부 Android App Links 문서에도 동일 인증서가 등록되어 있다.
- APK 안 JavaScript 번들과 이번 생성 출력의 바이트 일치 확인. APK 내용에서 현재 서버 비밀값과 서명 비밀번호가 발견되지 않았다.
- 커밋 대상에서 `.env`, 서명키, DB 백업, 의존성·생성 파일 제외 확인.

상세 값은 [APK 검증 JSON](2026-11-01_릴리즈_0.2.1.json)에 있다. 빌드 성공은 실제 계정 로그인이나 전체 앱 사용 흐름의 기기 검증 완료를 의미하지 않는다.
