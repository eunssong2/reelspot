현재 정책의 유일한 원본은 [기능명세서.md](기능명세서.md)(v3.1, 2026-11-04)입니다. v3.0은 디자이너·PM이 고객 요구를 반영하는 `feature/ui-prototype@870be87`을 실행·분석해 다시 썼고 v3.1에서 대조 보완과 추가 설계 표시를 반영했습니다. 0절에 바뀐 결정(D01~D24)과 확인 필요 항목(Q1~Q18)이 있습니다. 기능·권한·입력·한도·보관·완료 조건은 이 문서를 기준으로 변경합니다.

- [다이어그램](다이어그램/): 명세 8절의 유스케이스 원본 PlantUML과 PNG·SVG. `*_v1_2026-10-17.puml`은 이전 버전입니다.
- [참고 자료](참고%20자료/): 기능 조사, 이전 개요·설계 문서, 2026-10-17 명세 v1과 2026-10-30 명세 v2.3 원문을 보관합니다. 반복 일정·파일 공유 등 이후 제외된 기능이 있으므로 현재 개발 기준으로 사용하지 않습니다.
- [회의록](../회의록/README.md): 기능 결정의 원문과 반영 내역입니다.
- [1차 개발 설계서](../1차%20개발%20설계서/00%20설계서%20안내.html): 현재 정책을 구현할 UI·API·DB·업무 흐름 설계입니다.
