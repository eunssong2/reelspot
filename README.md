# ReelSpot · At that place — 앱 개발

`docs` 브랜치는 기능 명세·개발 설계·회의 기록·약관을 관리합니다. 2026-11-03부터 코드는 별도 브랜치에서 관리합니다.

| 브랜치 | 로컬 폴더 | 내용 |
| --- | --- | --- |
| `docs` | `samsun/docs` | 이 저장소. 기능명세서·1차 개발 설계서·회의록·약관 |
| `backend` | `samsun/backend` | API 서버·미디어 작업자·운영 웹·API 계약·배포, 테스트 서버(Docker) 실행 위치 |
| `frontend` | `samsun/frontend` | Android 앱(Expo/React Native), 앱 사용설명서·릴리즈 기록 |
| `feature/ui-prototype` | `samsun/feature-ui-prototype` | 디자이너·PM의 UI 프로토타입(기능 기준, 팀원 브랜치) |

네 폴더는 같은 저장소의 worktree라서 브랜치를 바꾸지 않고 동시에 열 수 있습니다. 각 폴더에서 `git pull`로 최신화합니다. 실제 카카오 로그인 완료와 일반 사용자 출시 준비는 별도 검증이 필요합니다.

제품의 동작과 정책은 **기능 명세서**, 이를 구현하는 구조와 계약은 **1차 개발 설계서**, 결정의 배경과 변경 이력은 **회의록**으로 분리했습니다.

```text
.
├── 기능 명세서/
│   ├── 기능명세서.md          # 현재 정책 원본: v3.0
│   ├── 다이어그램/           # 유스케이스 원본·PNG·SVG
│   └── 참고 자료/            # 이전 명세와 기능 조사 근거
├── 1차 개발 설계서/
│   ├── 00 설계서 안내.html    # 설계 v0.4 읽기 시작점
│   ├── UI/                   # 프로토타입 화면·전환·상태 설계
│   ├── 기준/                 # 검증용 명세 사본·SHA256
│   ├── 부록/                 # API·DB·검증 결과
│   ├── 참고 자료/            # 소개 PDF·선행 화면 명세
│   └── 도구/                 # 문서 재생성·검증 도구
└── 회의록/                   # 회의 내용·반영 내역·당시 참고 자료
```

최신 정책은 기능명세서 **v3.0**, 설계는 **v0.4**입니다(2026-11-03, UI 프로토타입 기준). 문서의 설계·계약 검증과 실제 앱 기능 검수를 구분합니다.

기능·정책을 바꿀 때는 `기능 명세서/기능명세서.md`를 먼저 수정합니다. 설계서의 `기준/기능명세서.md`는 독립 열람·재생성·SHA256 검증을 위한 사본이며 별도의 정책 원본이 아닙니다. 정책 차이를 확인한 뒤 사본과 설계를 함께 갱신합니다. `참고 자료`와 `회의록`의 과거 내용이 현재 정책과 다르면 최신 기능명세서를 따릅니다.

앱·서버 코드와 사용설명서·릴리즈·서버 운영 기록은 `frontend`·`backend` 브랜치에 있습니다. 원본 참고 앱 없이도 설계 문서를 열고 재생성할 수 있으며, 이전 APK 관찰 결과는 설계서 내부의 캡처·XML·기록으로 보존합니다.

테스트 빌드·서버: 최신 APK와 빌드 기록은 `frontend` 브랜치(`samsun/frontend/docs/`, 로컬 `samsun/frontend/at-that-place-release.apk`), HTTPS 테스트 서버 운영은 `backend` 브랜치의 `docs/2026-11-01_테스트_서버_운영.md`를 봅니다.

2026-11-03 v3 개정: 디자이너·PM이 고객 요구를 반영하는 `feature/ui-prototype@870be87`을 실행·분석해 [기능명세서 v3.0](기능%20명세서/기능명세서.md)과 [1차 개발 설계서 v0.4](1차%20개발%20설계서/00%20설계서%20안내.html)(UI·API·DB·업무 흐름·검수)를 다시 작성했습니다. 프로토타입과 겹치는 기능은 프로토타입 기준(D01~D24), 프로토타입에 없는 기존 기능은 유지, 확인 필요 항목은 Q1~Q14입니다. 화면별 출처는 [UI v3 적용 기준](1차%20개발%20설계서/UI/2026-11-03_UI_v3_적용기준.md)에 있습니다.
