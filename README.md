# 릴스팟 (ReelSpot)

## 한 줄 소개

**릴스팟은 여행 장소마다 스팟원들의 사진과 동영상을 함께 모으고, 여러 사람의 시선을 한 화면에 담은 여행 영상을 만드는 모바일 앱입니다.**

## 서비스 소개

같이 떠난 여행도 각자의 카메라에는 다른 순간이 남습니다. 릴스팟은 흩어진 여행 기록을 장소별로 모으고, 하나의 영상으로 완성합니다.

여행 방에 여행지와 기간을 설정하면 지도에서 주변 관광지, 맛집, 카페를 검색할 수 있습니다. 방문할 장소를 저장하거나, 장소를 선택해 사진과 동영상을 올릴 수 있습니다.

여행 방에는 방장을 포함해 최대 5명의 **스팟원**이 함께합니다. 같은 장소에 스팟원들이 올린 기록은 하나로 모여, 누가 어떤 순간을 남겼는지 함께 확인할 수 있습니다.

여행 영상을 만들 때는 한 화면 또는 분할 화면 템플릿을 선택합니다. 같은 장소에서 세 명이 찍은 사진과 동영상을 3분할 화면으로 동시에 보여 주는 등, 서로 다른 시선을 하나의 장면에 담을 수 있습니다. 장소별 장면을 이어 붙이면 우리만의 여행 영상이 완성됩니다.

## 주요 사용자

- 가족·친구와 함께 여행하고 각자의 사진을 한곳에 모으고 싶은 사람
- 영상 편집에 익숙하지 않지만 여행 영상을 남기고 싶은 사람
- 방문 장소와 추억을 연결해 다시 보고 싶은 사람

초기에는 40~60대 가족·친구 여행자의 사용 편의성을 중점적으로 고려하되, 연령에 관계없이 쉽게 사용할 수 있도록 설계합니다.

## 핵심 가치

### 장소를 중심으로 모이는 추억
대화방을 뒤질 필요 없이 지도와 장소별 보관함에서 여행 기록을 찾습니다.

### 최대 5명의 스팟원이 함께하는 기록
각자 찍은 사진과 동영상을 같은 여행 방에 올리고 함께 감상합니다.

### 여러 시선을 한 화면으로
분할 화면 템플릿으로 같은 장소에서 스팟원들이 남긴 서로 다른 순간을 동시에 보여 줍니다.

### 복잡한 편집 없이 영상 완성
자동으로 구성된 초안에서 미디어와 분위기를 간단히 조정하고 저장·공유합니다.

## 대표 사용 예시

제주도 여행 방에 다섯 명의 스팟원이 참여합니다. 지도에서 성산일출봉을 찾고, 방문한 뒤 각자 촬영한 사진과 동영상을 해당 장소에 올립니다.

방장이 3분할 템플릿을 선택하면 세 명의 스팟원이 남긴 기록이 한 화면에서 재생됩니다. 나머지 스팟원의 기록은 다음 장면에 배치할 수 있습니다. 카페와 해변의 기록까지 연결하면 여러 사람의 시선이 담긴 제주 여행 영상이 완성됩니다.

## 개발

```bash
npm install
cp .env.example .env     # Supabase URL / anon key 채우기
npx expo start
```

`.env` 없이 실행하면 **데모 모드**로 뜹니다. Supabase 없이 목 데이터로 화면을 확인할 수 있습니다.

### 데이터베이스

```bash
supabase link --project-ref <ref>
supabase db push
```

모든 테이블에 RLS가 켜져 있습니다. 여행 방은 그 방의 스팟원만 조회할 수 있고, 초대 코드로 참여하는 흐름은 `join_trip_by_code` 함수가 처리합니다.

### 구조

| 경로 | 역할 |
| --- | --- |
| `app/` | expo-router 라우트 (파일 = 화면) |
| `src/features/` | 기능 단위 UI·데이터 로직 |
| `src/lib/` | Supabase 클라이언트 등 공용 인프라 |
| `src/types/` | DB 타입 |
| `supabase/migrations/` | SQL 마이그레이션 |

### 테스트 케이스

`docs/test-cases.csv` 에 화면·기능·입력조건·기대결과를 정리합니다. **기능을 만들거나 고칠 때 같은 커밋에서 갱신합니다.**

| 컬럼 | 뜻 |
| --- | --- |
| 구분 | 정상 / 경계 / 예외 |
| 상태 | `통과` 는 실제로 확인한 것만. 확인 안 한 것은 `미실행` |

Excel에서 한글이 깨지지 않도록 UTF-8 BOM으로 저장합니다.

### 브랜치 전략

`main` ← `develop` ← `feature/*`.

### 현재 범위

로그인(카카오)과 스팟원 구하기까지 구현되어 있습니다.

- 여행 방 생성 (기간은 달력에서 범위로 선택), 초대 코드로 참여
- 스팟원 정원 1~5명 선택 (방장 포함), 방장이 나중에 변경 가능
- 분할 화면 배치 선택 — 칸 수가 정원과 맞물립니다 (`src/features/trips/layouts.ts`)

지도 검색, 장소별 기록 업로드, 실제 영상 생성은 아직 없습니다. 배치는 지금은 선택·저장만 하고, 영상 합성 단계에서 쓰게 됩니다.
