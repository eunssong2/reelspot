기준일은 2026-10-24입니다. 실제 소셜 인증과 Google 지도 키는 별도 설정이 필요합니다. 현재 개발 확인용 API는 `http://sphan0325.ddns.net:8081`입니다. 개발용 콘텐츠 판정 대역과 실제 운영 검수를 구분하며, 실행과 환경변수 설정은 코드 폴더의 README를 따릅니다.

`.env`, 계정·서버 비밀값, DB/업로드 원본, 로컬 도구·의존성·빌드 결과, APK/ZIP, 이전 참고 앱 소스와 원본 개인 대화는 Git에 포함하지 않습니다. `.env.example`, 실제 구현 소스, 설계 산출물, 검증 문서·근거는 포함합니다. 문서의 로컬 APK 경로는 각 환경에서 APK를 빌드한 뒤 사용할 수 있습니다.

확인용 APK 생성:

```bash
cd '1차 개발 코드/mobile'
npm ci
npm run preview:android -- --abi=x86_64,arm64-v8a
```

Android SDK/NDK·JDK 21과 API/DB/워커 설정은 [실행 안내](1차%20개발%20코드/README.md)를 참조하세요. APK는 개발 서명이며 출시용 서명 결과가 아닙니다.
