기능 ( 테스트때만 지도 google로 ?)

1. 지도 카테고리 줄 삭제
2. 지도 검색에 한글자만 쳐도 추천 장소 표시
3. 모임인원을 최대 15명으로 변경
4. 사진동영상 올리기 클릭 시 내가 올렸던 사진들이 직므이순간 남기기 밑에 뜨고 올렸던 사진을 x 클릭해서 삭제 할 수 있겠금
5. 내기록 수정 삭제 는 없어도 될것 같음 그냥 사진동영상 올리기 클릭해서 내가 올렷던 사진들과 삭제만 가능하게 해도 될듯 그리고 함께 남긴순간 밑에 내가 올린 사진 선택해서 개별적으로 삭제 할 수 있겠금
