# 미설계 화면 처리 방향

2026-11-10 검토 의견입니다. 번호와 화면명은 이 폴더의 기존 점검 캡처를 따릅니다.

| 번호 | 화면 | 처리 방향 |
| --- | --- | --- |
| No.1 | 촬영 결과 확인 | 카카오톡의 촬영 결과 확인 및 전송 흐름과 비교한 뒤 결정합니다. |
| No.2 | 기록 필터 시트 | 기록 필터는 우선 보류합니다. |
| No.3 | 기록 메뉴 시트 | 기존 점검 캡처의 별도 메뉴 시트는 우선 제외합니다. |
| No.4 | 일정 메뉴 시트 | 해당 화면이 현재 앱에서 사라졌으므로 검토 대상에서 제외합니다. |
| No.5 | 모임 관리 메뉴 | 현재 배포 앱의 [참여자 관리 메뉴](2026-11-10_현행_화면/N05_참여자_관리.png)를 따릅니다. 저장공간을 사용자가 별도로 확인할 필요가 있는지는 검토합니다. 모임 사진과 이름 변경은 ‘모임에 초대하기’ 화면에서 처리하는 방향입니다. |
| No.6 | 참여 관리 | 재참여 차단 목록은 우선 제외합니다. |
| No.7 | 모임 대표 사진 업로드 | 현재 ‘모임에 초대하기’ 화면의 ‘모임 사진 → 변경’을 사용합니다. |
| No.8 | 장소 추가 확인 시트 | 방문 날짜는 자동 설정되고 예정 시각은 나중에 별도로 설정할 수 있으므로, 해당 확인 시트는 우선 제외합니다. |
| No.9 | 알림과 처리 결과 | 화면의 용도와 요구사항을 먼저 확인한 뒤 처리 방향을 결정합니다. |
| No.10 | 약관과 동의 내역 | 화면의 용도와 요구사항을 먼저 확인한 뒤 처리 방향을 결정합니다. |
| No.11 | 개인 차단 관리 | 필요한 화면이므로 설계하고 구현합니다. No.6의 재참여 차단 목록과 별도 항목입니다. |
| No.12 | 문의하기 | 현재 ‘마이페이지 → 설정 → 문의하기’의 [화면과 흐름](2026-11-10_현행_화면/N12_문의하기.png)을 그대로 사용합니다. |
