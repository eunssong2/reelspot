개인정보 보호법 제15조 제1항 제4호의 계약 이행 근거는 해당 처리의 필요성을 확인한 후 사용할 수 있다. **이 근거만으로 제3자 제공까지 자동 허용되는 것은 아니다.** 서비스 전체를 ‘계약 이행’으로 묶지 않고 데이터 항목별로 판단한다. [제15조](https://www.law.go.kr/법령/개인정보보호법/제15조), [제17조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029334739)

## 권장 가입·이용 흐름 — 구현 제안

1. 로그인 전 약관·처리방침을 열람할 수 있게 하고, 소셜 로그인에서 어떤 정보를 받는지 안내한다. 공급자 정보가 가입 동의 전에 서버에 도착한다면 그 단계의 처리 근거와 미가입 데이터 파기도 정한다.
2. 가입 연령 정책을 적용한다. 소셜 로그인 성공을 나이 확인이나 법정대리인 동의로 간주하지 않는다.
3. `[필수] 서비스 이용약관에 동의합니다`를 제공한다. 계약 이행에 필요한 개인정보는 03번 안내를 제공하고, 별도 동의가 필요한 항목만 구분한다.
4. 모임에 참여할 때 표시명·역할 등 공유와 참여자 범위를 알리고 필요한 동의를 받는다. 사진·영상 제공은 업로드 전에 별도로 설명한다.
5. 현재 위치 버튼 사용 시 해당 지위에 필요한 위치 약관 동의와 접근권한 사전 안내·OS 승인을 각각 처리한다. 처리 주체·법적 지위 미확정 상태에서는 기능을 활성화하지 않는다. 카메라·마이크도 기능별로 선택 권한임을 알린다. 사진 선택기에는 전체 사진첩 권한을 요구하지 않는다.
6. 국외 이전이 발생하고 별도 동의 근거를 택했다면 해당 데이터 전송보다 먼저 받는다. SDK가 앱 실행과 동시에 보내는 경우도 포함한다.
7. 설정에서 문서 버전·선택·철회 내역과 삭제·권리행사 경로를 제공한다. 앱 밖 계정 삭제 요청 웹 경로, 비회원 권리침해 접수, 로그인 불가 시 회신 수단을 함께 마련한다. 법정 요청·사고 대응은 [12번](12_권리침해와_개인정보사고_대응절차.md)을 따른다.

‘전체 동의’는 편의 기능일 뿐이다. 선택 항목을 미리 체크하지 않고, 개별 거부와 내용 확인을 허용한다. 안내를 읽었다는 사실, 계약 동의, 개인정보 동의, 작업 확인을 같은 이벤트로 저장하지 않는다. [동의 방법](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1033215025)

## 동의 기록과 변경

- 문서 식별자·버전·본문 해시, 이용자 식별자, 동의 항목, 선택/철회, 서버 시각, 요청 식별자, 동의 화면의 설명 버전을 남기는 방안을 권장한다.
- 모임별 제공은 모임 식별자·제공 범위·수신자 확인 경로·동의 당시 범위도 필요하다. 법정대리인 확인은 확인 방식과 최소 증거를 별도로 관리한다.
- 동의 증거를 위해 주민등록번호·전체 IP·기기 고유번호를 자동으로 추가 수집하지 않는다. 필요한 경우 목적·법적 근거·기간부터 정한다.
- 동의 철회 후의 증빙 보관도 별도 근거와 기간이 필요하다. ‘분쟁 대비 영구 보관’은 채택하지 않는다.
- 개인정보 처리방침 변경을 전부 재동의 대상으로 취급하지 않는다. 동의 사항 변경 등 새 동의가 필요한 경우와 단순 고지 변경을 구분한다.
- 약관을 게시하거나 앱을 계속 사용했다는 사실만으로 모든 개인정보 동의를 대체하지 않는다.
