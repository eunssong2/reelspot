# 출시 전 결정사항과 현재 명세 검토

2026-10-30 · 검토 초안 v0.3 · 내부 실행 문서 · 상태: 현행 조문 대조·문서 보완, 운영·구현·개별 사안 법률 검토 미완료

이 문서는 약관 문구만으로 해결되지 않는 결정을 정리한다. 법적 위반을 확정한 목록이 아니라, 실제 사실과 법적 근거를 확인해야 할 항목이다. 이번 작업으로 기존 기능명세·API·DB·UI를 변경하지 않았다. 대신 [13번](13_기능명세_법령정합성_개정안.md)에 F02·F09·F20·F24 및 연관 조항의 교체 문안을 작성했다. 약관 v0.2는 그 개정안의 정책을 전제로 하므로 구현 전 게시할 수 없다.

## 3. 개인 PC 운영에서 실제 확인할 사항

- [ ] 운영용 서버·계정·저장소와 개인 작업을 분리하고 접근 가능한 사람을 특정한다.
- [ ] DB·파일·관리자 도구가 불필요하게 인터넷에 노출되지 않는지 확인하고, 인증·권한·통신 보호·업데이트·접속기록을 적용한다.
- [ ] 가족·방문자·수리 업체 등의 물리적 접근과 장비 반출·폐기에 대비한다.
- [ ] 자동 클라우드 동기화·OS 백업·오류 보고·원격 지원·터널·CDN 경로를 확인한다.
- [ ] 미디어 원본·변환본·썸네일·임시 파일·로그·백업을 모두 포함한 삭제를 검증한다.
- [ ] 복원 시험에서 삭제·만료된 파일이 재공개되지 않는지 확인한다.
- [ ] 토큰·초대 원문·미디어 본문·신고 증거가 일반 로그에 남지 않게 한다.
- [ ] 일반 이용자 접속 로그와 관리자 등의 개인정보처리시스템 접속기록을 구분하여 보존·점검 의무를 적용한다.
- [ ] 계정·방장 상태와 관계없이 권리 요청을 접수하고 처리 결과를 안내한다.
- [ ] 사고 인지·피해 차단·증거 보존·법정 통지/신고의 담당자와 절차를 마련한다. ‘모든 사고는 72시간’처럼 서로 다른 요건을 한 줄로 일반화하지 않는다.
- [ ] 개인정보 보호책임자 지정과 규모·유형별 추가 의무 적용 여부를 확인한다.

이는 약관 동의 항목이 아니라 운영자의 내부 의무·구현 점검이다. 구체적 적용은 [현행 안전성 확보조치 기준](https://www.law.go.kr/admRulInfoP.do?admRulSeq=2100000281400)과 관련 법령을 따른다.

### 플랫폼·신고·사고 대응 추가 점검

- [ ] 로그인 없이 열리는 공개 개인정보 처리방침 URL과 앱 내 링크를 제공하고 실제 데이터·SDK 처리와 Play 데이터 보안 응답을 일치시킨다.
- [ ] 앱 내 삭제와 앱 밖 웹 요청 경로를 제공한다. 웹 요청은 안내·접수 양식 등의 방식도 가능하지만 앱 재설치를 요구하지 않고 본인 확인과 실제 처리까지 연결한다.
- [ ] UGC 업로드 전 약관 동의, 콘텐츠/이용자 신고, 개인 차단, 운영 조치를 검증한다. 비공개 모임의 UGC도 Play 정책 검토에 포함한다.
- [ ] 대상 연령을 확정해 스토어에 선언하고, 아동 대상인 경우 별도 가족·아동 정책 적용을 확인한다.
- [ ] 카카오 로그인 동의항목과 실제 요청·보관 필드를 맞추고 탈퇴 시 연결 끊기 API, 외부 해제 웹훅·실패 재시도를 구현한다.
- [ ] 저작권 중단·재개 수령인과 연락처·양식을 공개하고 법정 기간 추적·통보를 검증한다.
- [ ] 공개 유통 여부와 조치의무사업자 지위를 기록하고, 일반 신고보다 빠른 불법촬영물등 대응 경로를 운영한다. 삭제된 아동·청소년성보호법 제17조를 근거로 사용하지 않는다.
- [ ] 유출등 정보주체 통지와 감독기관 신고를 분리하고 해당 인지 시각·요건·72시간 기한·예외·보완 통지를 기록한다.
- [ ] 백업 30일 일괄 잔존 없이 파기할 수 있는 구조와 파기 기록·책임자 확인을 갖춘다. 운영이 불가능하면 정책 문구만 약속한 상태로 출시하지 않는다.

법령·플랫폼의 구분과 공식 출처는 [10번](10_법적근거와_출처.md) 제8~10항을 따른다.

| 운영자 열람 | 대상·목적별 적법 근거, 담당자별 최소 권한, 열람 기록·점검과 목적 외 접근 차단 |
| 권리침해·재개 | 반박내용 게재 요청·통지 수단 지정, 소명자료 판단·법정 통보·예정일 실제 재개와 소 제기 예외 |
| 운영자 해지 | 중대한 사유·비례성 검토, 통지 도달부터 최소 7일 소명, 제한 계정의 권리행사·적법한 본인 자료 반환 |
| 변경 미동의 | 기존 약관 유지·새 처리 차단. 기존 제공 불가능 시 정당한 종료 근거·통지·소명·자료 반환 절차 |

여기 적은 검수는 아직 수행하지 않았다. 체크 표시를 완료로 바꾸려면 실행 증거가 필요하다.

1. 무료 모임 미디어 서비스의 처리 항목별 적법 근거와 동의 구성은 적절한가?

8. 개인 운영 형태에서 추가 등록·신고·공개·안전조치 의무가 있는가?
