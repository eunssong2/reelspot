# 가입 시 받을 약관 — 적용 안내

2026-10-30 · 내부 적용 안내 · 이 README는 사용자 동의 대상이 아님

가입 화면에서 체크할 항목과 전문을 복사하기 위한 폴더다. 현재 확정 가능한 기본 체크 항목은 **서비스 이용약관 동의 1개**다. 개인정보 처리의 실제 근거·국외 이전·가입 연령이 정해지면 가입 단계의 추가 절차가 필요한지 다시 판단한다. 서비스 전체에서 이 동의 하나만 받으면 된다는 뜻은 아니다.

## 복사할 파일

| 파일 | 가입 화면 체크 문구 | 사용 방법 |
| --- | --- | --- |
| [01 필수 서비스 이용약관](01_필수_서비스_이용약관.md) | `[필수] 서비스 이용약관에 동의합니다.` | ‘체크박스 문구’를 체크 항목으로, ‘체크 항목 아래 안내’와 ‘주요 내용’을 설명으로, ‘서비스 이용약관 전문’ 이하를 전문 보기 화면으로 사용 |

파일에서 내부 검토 설명·문서 번호 참조·근거 부록을 제거했다. **`{{...}}`는 아직 알 수 없는 운영 정보를 넣는 자리다. 이 값을 채우고 실제 기능을 확인하기 전에는 그대로 공개하지 않는다.** 법률 검토를 완료한 최종본이 아니라 기존 v0.3 초안에서 정리한 게시 문안이다.

체크는 처음에 해제된 상태로 표시하고 전문을 가입 전에 열어볼 수 있게 한다. 계약 동의의 문서 ID는 `terms-service`로 관리하며, 확정한 버전·본문·동의 시각을 연결해 기록한다. ‘주요 내용’은 전문을 대체하지 않는다. 하나의 체크 항목이면 ‘전체 동의’ 체크를 추가할 필요가 없다.

## 게시 전에 채울 값

| 입력 자리 | 넣을 내용 |
| --- | --- |
| `{{서비스명}}` | 앱·스토어에 사용할 최종 서비스 이름 |
| `{{운영자명}}` | 실제 계약 책임자인 개인 성명 또는 등록된 사업자명. 프로젝트명만으로 대체하지 않음 |
| `{{운영자_전화번호}}` | 운영자가 응대할 실제 전화번호 |
| `{{문의_이메일}}` | 실제 수신·답변 가능한 이메일 |
| `{{추가_운영자_표시사항}}` | 적용 법령에 따라 필요한 실제 주소·등록 정보 등을 완성된 문장으로 입력. 적용되는 추가 표시사항이 없다면 이 자리 삭제. 위치 약관의 주소 표시 판단과 구분 |
| `{{가입연령_및_법정대리인절차}}` | 확정한 최소 가입 연령 및 필요한 법정대리인 절차를 완성된 문장으로 입력. 만 14세·만 19세 등 미정 값을 임의로 넣지 않음 |
| `{{권리침해_신고경로}}` | 비회원도 사용할 수 있는 신고 URL·연락처 |
| `{{저작권_요청_수령인과_연락처}}` | 지정 수령인 성명/부서·이메일·전화·우편주소·중단/재개 요청 양식 URL |
| `{{계정삭제_요청경로와_절차}}` | 앱 밖 웹 요청 URL과 본인 확인·회신 절차 |
| `{{방장탈퇴시_모임처리정책}}` | 후임 지정 및 후임 없는 경우의 실제 모임 처리 방법 |
| `{{공지_URL}}` | 공개 공지 페이지 주소 |
| `{{시행일}}` | 실제 약관 시행일 |
| `{{약관_변경이력_URL}}` | 이전 버전·변경 이력을 볼 수 있는 공개 주소 |

특히 파일의 GPS 제거·파기/백업·방장 탈퇴·개별 통지·신고 처리·운영자 열람 통제·해지·변경 미동의 처리 내용은 현재 구현 완료가 확인되지 않았다. [기능명세 개정안](../13_기능명세_법령정합성_개정안.md)에 따른 개발·검증과 실제 정책 확정 후 공개한다. 관련 법적 근거는 [10번 출처](../10_법적근거와_출처.md)에 있다.

## 체크 항목으로 만들지 않은 문서

가입 화면에는 체크 항목 외에 **개인정보 처리 안내와 처리방침 열람 링크**도 제공한다. 별도 체크박스가 없다는 이유로 안내를 생략하지 않는다. 실제 정보가 소셜 로그인 직후 서버에 도착한다면 그 전에 필요한 안내·처리 근거를 마련한다.

| --- | --- |

## 이번 보완의 적용 조건

가입 체크 항목은 1개로 유지한다. 주요 내용에 콘텐츠 이용 허락, 제한된 운영자 열람, 이용 제한·해지, 변경 미동의 처리를 추가했다. 제10조의2의 최소 7일 소명 기간은 법정 공통 기한이 아니라 이 서비스가 제안한 계약상 약속이다. 알림 도달 확인, 제한 계정의 소명·자료 반환, 약관 버전별 적용을 구현·검증한 뒤 게시한다. 문안의 기간을 바꾸려면 원본·사본·운영 절차를 함께 수정한다.
