# 삼선 프로젝트 출시용 약관·개인정보 문서

작성·법령 확인일: **2026-10-30** · 버전: **검토 초안 v0.3** · 대상: 대한민국 일반 이용자

이 폴더는 어떤 동의를 언제 받아야 하는지 설명하고, 서비스에 맞는 약관·방침·동의문 초안을 제공한다. **법률 검토를 완료한 게시본이 아니다.** `[확정 필요: …]`를 실제 사실로 채우고, 적용 조건을 결정하고, 구현과 법률 검토를 마친 뒤 게시한다. 체크박스를 많이 받는 것으로 위법한 처리가 적법해지는 것은 아니다.

## 확인된 전제

- 운영 프로젝트명: **삼선**. 제품명은 기존 명세의 **At that place / ReelSpot**을 참고했으며 최종 공개 명칭은 미정이다.
- 운영자 확인: 아직 사업자등록을 하지 않았고 **운영자 개인 컴퓨터에 서버를 구축할 예정**이다. 실제 운영자 성명·주소·연락처, 서버 설치 국가, 백업 방식은 미확정이다. 프로젝트명을 법인명으로 취급하지 않는다.
- 대한민국 출시, **최소 가입 연령 미정**. 연령 제한이나 법정대리인 동의 방식을 임의로 확정하지 않았다.
- 정책 기준: [기능명세서 v2.1](../기능%20명세서/기능명세서.md). 무료 Android 1차 서비스이며 카카오·Google 로그인, 모임·일정·장소, 사진·영상 업로드·공동 열람·기기 저장을 포함한다.
- 지도는 현행 명세상 카카오맵이며 Google Maps 전환은 조사 단계다. 검사 업체, 외부 SDK, 중계·메일·백업 업체는 확정되지 않았다.

## 지금의 결론

가입 시 **서비스 이용약관 동의**를 받고 **개인정보 처리방침을 쉽게 열람**하도록 한다. 개인정보 수집·이용 동의는 실제 처리 근거에 따라 정한다. 현재 위치는 기능 이용 시 별도로, 모임 내 개인정보 공유는 대상 모임별로 처리한다. 국외 이전·광고·아동 관련 동의는 실제 적용 조건이 생길 때만 활성화한다. 상세 요건은 00번 문서를 따른다.

특히 방장 역할 미정리로 탈퇴를 계속 막는 현행 명세, 위치 태그 원본 보관, 새 참여자에게 기존 파일이 공개되는 범위, 내려받은 사본의 이용 기간은 출시 전 해소해야 한다. v0.2에서는 계약 근거 가입 안내, 접근권한 고지, 비회원 출처 안내, 법정 권리행사·사고 대응, 저작권 절차를 보완했다. GPS 원본 장기 보관과 백업 30일 일괄 잔존을 없애는 정책안도 반영했다. **기능명세·API·DB·UI 원본은 변경하지 않았고, 교체 문안·반영 대상·검증 조건을 13번에 정리했다. 약관 문안과 실제 구현이 일치하기 전에는 게시하지 않는다.**

v0.3에서는 삭제·반박내용 게재 요청, 저작권 재개의 실제 실행, 비공개 콘텐츠 열람 통제와 이용 허락 요약, 운영자 해지·변경 미동의 처리 절차를 원본과 가입용 사본에 함께 보완했다. 가입 기본 체크 항목은 1개로 유지한다. 최소 7일 소명 등 새 계약상 약속과 관련 구현·검증 과제는 12·13번에 기록했다. 변경하지 않은 개별 문서는 기존 버전을 유지한다.

## 게시본으로 바꾸는 절차

1. 09번의 미확정 사항을 결정하고 운영 책임자를 기재한다.
2. 실제 앱·서버·SDK의 데이터 흐름과 문서의 항목·수신자·국가·기간을 대조한다.
3. 조건에 맞지 않는 예비 조항과 내부 설명을 삭제하고, 공개용 문서의 버전·시행일을 부여한다.
4. 개인정보·위치정보·IT 서비스 계약을 다루는 국내 변호사에게 쟁점과 초안을 함께 검토받는다. 필요한 신고·등록 여부는 별도로 확인한다.
5. 동의·철회·삭제·백업 복원·권한을 검증한 뒤 공개한다. 문서에 약속한 기능이 없는 상태로 게시하지 않는다.

이번 작업은 문서 작성이다. 실서비스 배포, 사업자등록, 위치 관련 신고, 실제 개인정보 수집·삭제 검증은 수행하지 않았다.
