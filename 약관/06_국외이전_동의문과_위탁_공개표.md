# 국외 이전 동의문과 처리위탁 공개표

2026-10-30 · 검토 초안 · 실제 업체·국가·흐름 확정 전 게시 금지

## 1. 개인 PC 서버에서의 판단 순서

사용자는 개인 PC에 서버를 운영할 계획이다. 서버 소재 국가와 백업 위치는 별도로 확인한다. 본문을 작성할 때 **운영자가 직접 보관하는 것**, **업체가 운영자의 지시로 처리하는 것**, **업체가 자체 목적으로 이용하는 것**을 구별한다.

| 경로 | 현재 확인 상태 | 확인해야 할 내용 |
| --- | --- | --- |
| 계정 DB·미디어 파일 | 개인 PC 운영 계획 | 설치 국가, 저장 장치, 암호화·권한, 백업·원격 지원 |
| 카카오·Google 로그인 | 기능명세에 포함 | 앱·서버가 받는 항목, 공급자로 보내는 식별자·인증 정보, 공급자의 독립 처리와 위탁 구분 |
| 지도 | 현재 명세 카카오맵, Google Maps 도입 미정 | 검색어·좌표·IP·기기 정보의 실제 수신자·국가·저장, SDK 자동 전송 |
| 콘텐츠 검사 | 엔진·업체 미정 | 로컬 처리 여부, 외부 전송 파일·프레임·텍스트, 보관·재사용·학습·재위탁 |
| 오류 수집·분석·메일·푸시 | 실제 사용 여부 미정 | 앱 시작 시 자동 수집 포함, 수신자·데이터·국가 |
| CDN·터널·원격 중계 | 사용 여부 미정 | 통신 종료 지점, 로그·본문 처리, 운영자·지원자의 국외 조회 |
| 백업·동기화 | 미정 | OneDrive 등 개인 PC 자동 동기화 포함, 저장 국가·접근·파기 |

외국 업체라고 무조건 모든 데이터가 국외 이전되는 것은 아니며, 국내 저장을 선택했다고 국외 지원 인력의 조회까지 없어진 것도 아니다. 업체명만으로 단정하지 않고 설정·계약·전송 내역을 확인한다.

일반적인 처리위탁은 이용자의 포괄 동의 대신 법정 위탁 계약·공개·관리감독을 갖추는 방식으로 처리한다. 계약에는 목적 외 이용 금지, 접근 제한·보호조치, 재위탁, 감독, 종료 시 반환·파기, 사고 대응과 책임 등을 구체화한다. 업체가 자체 학습이나 광고에 이용하면 단순 위탁으로 볼 수 있는지 재검토한다. [개인정보 보호법 제26조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029335715)

## 3. 국외 이전의 법적 근거 선택

개인정보 보호법 제28조의8에 따라 별도 동의, 법률·조약상 근거, 계약 체결·이행에 필요한 처리위탁·보관과 법정 공개/통지, 인정된 인증·국가 등 적용 가능한 근거를 실제 요건에 맞게 판단한다. **‘국외 이전이면 언제나 필수 동의’도, ‘방침에 쓰면 언제나 가능’도 아니다.**

특히 계약 이행에 필요한 **처리위탁·보관** 경로를 외부 업체의 독자적 목적의 **제3자 제공**에 그대로 적용하지 않는다. 국외 이전 근거와 제3자 제공 근거는 필요한 경우 각각 충족해야 한다. [개인정보 보호법 제28조의8](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029331957)

## 5. 동의 외 근거를 사용하는 경우의 공개 문안 틀

> [운영자]는 [구체적 계약 이행 업무]에 필요한 개인정보의 [처리위탁/보관]을 위하여 개인정보 보호법 제28조의8 제1항 제3호의 요건에 따라 아래와 같이 국외로 이전합니다. 이전 항목·국가·수신자·시기·방법·목적·기간과 이전 거부 절차·효과는 아래 표와 같습니다.

4항과 같은 정보를 채우되 **‘동의합니다’ 체크박스를 기계적으로 붙이지 않는다.** 요건 충족 판단과 업체 보호조치 검토 기록을 내부에 보관한다. 적용 근거가 달라지면 해당 법적 근거로 문장을 바꾼다.

## 6. 출시·변경 확인

- SDK 초기화·파일 전송보다 앞서 필요한 고지·동의가 이루어지는지 확인한다.
- 계약상 목적 외 이용·학습·재위탁·지원 접근과 실제 기본 설정을 확인한다.
- 국외 이전 관련 안전조치와 권리행사·삭제 전파·사고 연락 절차를 확보한다.
- 수신자·국가·목적·기간 등이 바뀔 때 동의 변경 요건 또는 공개·통지 절차를 적용한다.
- 사업자·인프라가 정해지지 않았다는 이유로 가상의 업체나 국가를 기입하지 않는다.

## 공급자 정책 추가 확인 — 2026-10-30

개인정보 보호법상 국외 이전 근거를 정한 뒤에도 이용 중인 공급자의 계약·정책을 확인한다. [카카오 로그인 공식 문서](https://developers.kakao.com/docs/ko/kakaologin/common)는 카카오 API로 제공받은 정보의 국외 이전과 탈퇴 후 보관에 별도의 고지·동의 정책을 안내한다. 법률상 동의 외 근거가 있다는 사실만으로 공급자 정책까지 충족했다고 판단하지 않는다. 실제 카카오 정보가 해외 저장·조회·백업되는지, 삭제 재시도 정보에 남는지 확인하고 적용 정책을 기록한다. 법정 보존 의무와 공급자 정책이 충돌하는 것으로 보이는 경우 항목별 근거·최소 보관을 확인하고 공급자 문의·법률 검토 후 확정한다.
