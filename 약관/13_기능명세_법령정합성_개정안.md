# 기능명세 법령 정합성 개정안

2026-10-30 · 검토 초안 v0.3 · 대상: [기능명세서 v2.1](../기능%20명세서/기능명세서.md)

**이 문서는 교체할 문안을 준비한 개정안이다. 기능명세 원본·설계 사본·API·DB·UI·생성 산출물은 변경하지 않았다.** 약관 v0.3의 탈퇴·파기·위치 태그·운영자 열람·해지·변경 미동의 정책을 게시하기 전 이 개정안을 개발 설계에 반영하고 검증해야 한다. 현행 문서를 준법 구현 완료본으로 취급하지 않는다.

법률이 요구하는 결과와 제품의 구현 선택을 구분한다. 예를 들어 개인정보 최소화·지체 없는 파기는 법적 의무이고, 업로드 전 GPS 제거·라이브 파일 24시간 정리는 이 서비스를 위한 구현안이다. 법률이 특정 후임 선임 알고리즘이나 모든 로그의 같은 보관 기간을 정한 것은 아니다.

## 1. F02 가입 동의·표시명 설정 — 관련 항목 교체안

- **입력:** 서비스 이용약관 동의, 개인정보 처리 안내 확인 경로, 실제 필요한 목적별 동의, 표시명.
- **가입:** 이용약관 동의와 연령 정책에 따른 가입 요건을 확인한다. 개인정보 처리방침 전체에 대한 필수 동의는 받지 않는다. 계약 체결·이행에 필요한 가입정보는 항목·목적·근거·기간을 안내하고 필요성을 기록한다. 선택 동의 거부로 핵심 서비스 이용을 막지 않는다.
- **표시명:** 직접 입력을 기본으로 한다. 소셜 이름을 초기값으로 받는 기능을 유지하려면 실제 수신 항목·필요성·법적 근거를 확정하고 로그인 공급자의 설정과 처리방침을 일치시킨다. 공백만 있는 이름은 거부하고 중복 이름은 허용한다.
- **기록:** 문서·항목 버전, 동의 선택·변경·철회 시각을 저장한다. 처리 안내의 제공 기록·약관 계약 동의·개인정보 동의·OS 접근권한을 다른 사건으로 기록한다. 증빙 항목·기간도 별도 확정한다.
- **설정:** 항목별 동의 철회는 해당 처리·기능에만 적용한다. 계약 근거 처리에는 개인정보 권리행사 경로와 이용계약 해지 경로를 제공한다. 모든 동의 철회를 F24 계정 삭제로 자동 연결하지 않는다. 실제 조치 전 완료로 표시하지 않는다.

근거: 개인정보 보호법 제15조 제1항 제4호, 제22조 제3·5항, 제37·38조. 가입 연령은 [08번](08_가입연령과_법정대리인_동의.md)에서 미확정 상태를 유지한다.

## 2. F09 현재 위치 — 해당 항목 교체안

- **현재 위치:** 버튼을 누른 경우에만 필요한 위치정보 이용 동의와 선택 접근권한 안내·OS 승인을 각각 처리한 뒤 위치를 획득한다. 필요한 정확도·수신자·기간을 확정하며, 백그라운드 추적과 사진 촬영 위치의 자동 기록은 하지 않는다.
- **거부·철회:** 위치 권한 거부·획득 실패·위치 이용 동의 철회 시 현재 위치 기능을 중단하고 장소 검색·직접 등록을 제공한다. 이미 전송된 자료의 법정 파기는 OS 권한 변경과 별도 처리한다.
- **출시 조건:** 기기→운영자 서버→지도 SDK/업체의 실제 흐름, 위치정보법상 지위·신고/등록·약관·확인자료·제공 통보 의무를 확정한다. 서버 미저장이나 기기 내부 처리라는 이유만으로 자동 적용 제외로 결론내리지 않는다. 미확정이면 현재 위치 기능을 활성화하지 않고 검색·직접 등록 경로만 제공할 수 있도록 설계한다.

근거: 정보통신망법 제22조의2, 위치정보법 제19·24조. 마지막 지도 영역과 이용자가 지정한 장소는 현재 위치 좌표와 별도로 평가한다.

## 3. F20 촬영 위치 메타데이터 처리 — 교체안

- **대상:** 사진·영상·대표 사진의 업로드 입력 및 서버 보관·제공 파일.
- **규칙:** 휴대폰 원본을 변경하지 않고 업로드용 사본에서 EXIF GPS·영상 위치 태그를 제거한다. 서버에서도 제거 여부를 검증하고 검증된 파일만 서비스 보관·썸네일·열람본·저장본·백업의 원천으로 사용한다.
- **예외 유입:** 위치 태그가 남은 입력은 공개하지 않고 격리해 즉시 제거하거나 거절한다. 해당 입력·임시본을 장기 원본 저장소·일반 로그·백업으로 보내지 않는다. 유입 자체의 처리 근거와 최소 일시 처리 방식을 검토하고 불필요해진 임시본은 지체 없이 파기한다.
- **보존:** 촬영 날짜·시간·방향·영상 길이·음성은 필요한 범위에서 유지한다. 없는 값을 만들지 않는다. 직접 지정한 방문 장소와 사진 내용의 위치 단서는 별도 정보이며 자동 익명화됐다고 설명하지 않는다.
- **실패:** 제거·검증에 실패하면 파일별 업로드 실패/재시도·지원 형식 안내를 제공한다. 실패 입력을 무기한 남기지 않는다.
- **완료 조건:** 지원 형식별 입력·저장 파일·파생본·백업·로그의 GPS 부재, 중단·실패 후 임시본 파기를 확인한다. 별도 목적의 GPS 원본 보존을 추가하려면 새 필요성·근거·기간·위치정보법 검토를 먼저 한다.

근거: 개인정보 보호법 제3·15·16·21조. 원본 보관 자체를 모든 경우 불법이라고 단정한 개정이 아니라, 현재 기능에서 불필요한 위치정보 보유를 줄이는 안이다.

## 4. F24 계정 삭제 — 교체안

- **사용자·접수:** 본인 확인을 거친 이용자. 앱의 계정 삭제와 앱 설치 없이 이용할 수 있는 공개 웹 요청 경로를 제공한다. 로그인 불가·정지 상태에는 대체 본인 확인·회신 경로를 제공한다.
- **역할 정리:** 방장 모임과 후임 지정 방법을 안내하되 역할 정리를 삭제 요청의 접수 조건으로 삼지 않는다. 역할 이전 실패·후임 부재와 계정 삭제 작업을 분리한다. **[확정 필요: 후임 없는 모임의 자동/운영자 이전 또는 종료 방식, 선정 기준·통지·경쟁 처리]**. 이 결정은 모임 운영 정책이며 개인정보 권리행사 기한을 연장하는 근거가 아니다.
- **확인:** 참여 중·이미 나간·퇴장된·종료된 모든 모임의 본인 서버 파일 삭제와 타인 파일·기기 사본의 차이를 안내한다. 다른 작성자 파일 속 본인 개인정보의 권리 요청 경로도 제공한다.
- **처리:** 본인 확인과 삭제 의사 확인 후 계정의 신규 서비스 이용·업로드·역할 수신을 차단한다. 전체 본인 기록을 식별해 접근 차단·원본/파생본/임시본/백업 파기·집계 정리를 수행한다. 법정 보존 항목만 근거·기간을 알리고 분리한다. 요청·처리중·완료·법정 예외를 구분하고 실패 작업은 재시도·경보한다.
- **외부 연결:** 탈퇴 과정에서 카카오 연결 끊기 API를 호출하고 공급자별 토큰·연결 해제를 처리한다. 외부 API 장애를 무기한 탈퇴 거절 사유로 쓰지 않고 최소한의 재시도 정보와 기한을 정한다. 외부에서 연결 해제한 경우의 웹훅·계정 상태 처리도 정의한다.
- **완료 조건:** 역할 이전·신규 모임 생성·업로드 완료와의 경쟁 상황에서도 삭제가 되돌아가지 않는다. 요청을 접수했다는 사실만으로 파기 완료를 표시하지 않는다. 법정 권리행사와 결과 통지는 02번 제9항의 기한을 적용한다.

근거: 개인정보 보호법 제21·37조, 제38조 제4항, 시행령 제41~44조. 앱 밖 삭제 경로·카카오 연결 해제는 별도의 플랫폼 정책 요건이다.
