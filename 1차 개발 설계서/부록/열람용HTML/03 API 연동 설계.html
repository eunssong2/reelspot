At that place 1차 API 연동 설계

1차 개발 구현 설계 v0.3 · 기준 기능명세서 v2(2026-10-22) 우선 · 2026-10-22

부록/openapi.json은OpenAPI3.1구현계약안이다. 서버주소example.invalid는실제배포주소가아니다. 모든operationId는화면/기능/검수추적표와연결한다. 인증과운영권한·공개전검사·도메인검증은스키마만으로완성되지않으며서버에서집행한다.

1 공통 요청과 응답

구분계약
기본경로/v1. 실제 도메인은 배포시 주입. JSON UTF-8, 업로드 PATCH는 바이너리.
인증Authorization: Bearer. auth/exchange·문서·초대미리보기는 공개,refresh는 본문 refreshToken 검증.
멱등업무 쓰기 Idempotency-Key(16~128자),actor+route+key유일. 업로드 PATCH는 세대·offset·청크해시로 중복 판정.
버전expectedVersion과 필요시 previewId. 충돌409는 입력 유지·최신값 확인.
정상확정200 또는 접수202 Operation. 키는 operationId로 통일. HEAD/PATCH 성공은204와 전송 헤더. 전송100%는 완료 아님.
오류{code,message,requestId,retryable,operationId?,currentVersion?,itemErrors?}. HEAD 오류는 본문 없이 X-Error-Code/X-Request-Id.
페이지모임30개·파일60개. opaque cursor에 필터/정렬/actor/snapshotAt와 마지막 정렬키 서명.
목록스냅샷snapshotAt 뒤 완료 파일은 갱신에서 반영. 삭제·차단·만료는 즉시 제외.
필드삭제apply/value 명시. 설명 빈문자열은 비우기,visitId:null은 미지정. 누락 필드는 유지.
파일GET인증된 thumbnail/view/export만. Range 재검증·private/no-store. 위치포함 원본GET 없음.
파일전송ATP-Upload/1: 인증 HEAD/PATCH·offset·generation·SHA256·24h transport.09 문서·예제 참조.
