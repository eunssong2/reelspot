# 2026-10-30 고객 UI 통합 검토 결과

기준: 기능명세 v2.3 / 설계 v0.3.3 / 고객 UI `feature/ui-prototype@a67ee60368819ce5a325b5fe2ace17f9c85140c1`.

UI 원본은 별도 worktree에서 `git pull --ff-only origin feature/ui-prototype`로 갱신했다. 기존 개발 브랜치의 앱 코드에 원격 예시 저장소를 병합하지 않았으며, 원본 UI의 추적 파일도 변경하지 않았다. `feature/ui-prototype_es`는 확인 시 같은 커밋이었다.

## 반영한 요구

- UI01~UI06·UI23·UI24의 로그인·가입·모임·달력·일정 편집·초대 구성과 연속 기간 선택 시트.
- 세션/보류 초대 복원, 가입 뒤 분기, 로딩·빈 목록·오류 구분, 미저장 이탈, 입력 보존, 처리 중/결과 불명과 충돌 복구.
- 42일 달력·월과 겹치는 일정 목록·안정 정렬·늦은 월 응답 폐기·모든 현재 참여자의 초대 관리.
- 확정사항에 따라 카카오만 노출, 이용약관 필수 체크1개와 체크 없는 개인정보 안내, 모임/내 기록/마이페이지 탐색.
- 문서 API의 `kind=consent|notice`, 제목·항목 식별값·HTTPS 본문 링크와 DB의 종류·제목·게시 본문 및 고지 필수 체크 금지 제약. 운영 DB에는 적용하지 않았다.

## 생성·검증 범위

- 고객 UI 실행 캡처36개: 제품 화면19개와 관련 상태17개. 전체 제품 화면은35개다.
- UI01/02/03의 제품 적용 도형3개를 고객 원본과 별도로 추가했다. 원본의 Google 버튼·개인정보 필수 체크를 제품 요구로 오인하지 않게 했다.
- Word·PDF·PowerPoint·Excel·HTML·JSON·SVG와 OpenAPI·DB 컬럼 사전·명세 기준선을 함께 재생성했다. UI PDF56쪽, PPTX58장.
- OpenAPI 예제24건, 전용 임시 PostgreSQL 검증10건, 원본 앱/상위 문서 없는 독립 재생성5건, 산출물 검사45건이 통과했다. SVG 화면 경계 문제는0건이다.
- 검수 계획은 기능120개와 UI 통합23개다. 이 수는 실제 앱 기능 테스트 통과 건수가 아니다.

## 남은 결정

비연속 날짜·기록 정렬·일정별 커버·프로필 사진·코드 길이 등은 해당 안건을 따른다. 가입 연령·운영 정보·GPS 원본 처리·방장 계정 삭제 정책 등 A13은 일반 사용자 출시 전 해결해야 한다. 위 기록은 앞선 명세·설계 문서 작업의 결과다. 후속 앱 구현과 APK 빌드 범위·검증·제약은 [릴리즈 빌드 검증](../../1차%20개발%20코드/docs/2026-10-30_릴리즈_빌드_검증.md)을 따른다. 법령 재조사와 실제 카카오 계정 로그인 완료는 검증 범위에 포함되지 않는다.
