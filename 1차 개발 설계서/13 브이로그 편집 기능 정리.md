# 13 브이로그 편집 기능 정리

2026-11-28 · 기준 feature/ui-prototype@a88e986(11월 27일 문서는 @702ba0c), frontend@2b3aac2, backend@622ee17

최신 프로토타입의 편집·미리보기 동작과 제품 채택 여부를 기록합니다. 제품의 승인된 출력은 11번 설계와 F30을 따릅니다. 확장 편집값·원음 음소거·BGM은 제품 채택 대기입니다.

## 1 지금 프로토타입에 있는 기능

### 장면 편집 화면 구조
- 위에 미리보기를 고정하고 아래 설정만 스크롤합니다. 제목은 작은 글씨로 두어 사진이 중심입니다.
- 이어 재생이면 장면마다 작은 사진 그림이 한 줄로 나오고, 누르면 그 장면으로 갑니다. 하단은 한 줄 버튼이며 장면이 더 남았으면 "완료 | 다음 장면 (2/4)", 마지막 장면이면 "이 장소 완료"입니다.
- 오른쪽 위의 "▦ 템플릿 바꾸기"로 템플릿 선택 화면에 갔다가 고르면 편집 화면으로 돌아옵니다(사진이 2개 이상이고 맞는 템플릿이 있을 때).
- 미리보기 오른쪽 아래의 작은 ↶ ↷로 되돌리기·다시 적용을 합니다(최대 40번). 끌기·확대처럼 이어지는 변경은 한 번으로 묶입니다. 편집 화면에 들어올 때 기록을 비웁니다.
- 설정은 아코디언(한 번에 하나 열림)이고 접힌 줄에 지금 고른 값이 보입니다. 설명 문구는 짧게 줄였습니다.

### 효과 (옆으로 넘기며 고르는 줄)
| 항목 | 개수 | 내용 |
| --- | --- | --- |
| 색감 효과 | 14 | 원본, 밝게, 어둡게, 흑백, 따뜻하게, 차갑게, 필름, 빈티지, 선명하게, 페이드, 시네마, 누아르, 몽환, 노을 (지금 사진에 입힌 미리보기 그림) |
| 장면 전환 | 13 | 없음, 페이드, 옆으로, 위로, 확대, 축소, 흰 번쩍, 검게, 블러, 회전, 팝, 와이프, 원형 |
| 사진 움직임 | 7 | 없음, 천천히 확대·축소, 왼쪽·오른쪽·위·아래로 |

### 템플릿 (사진 개수 1~5)
- 63개: 1장 8, 2장 15, 3장 15, 4장 13, 5장 12.
- 선택 화면 맨 위 탭으로 묶습니다: 전체 · 기본 분할 · 폴라로이드 · 카드·여백 · 강조 배치 · 겹치기.
- 폴라로이드류는 칸마다 기울기(`rots`)·흰 테두리(`look`: polaroid/card)·바탕색(`bg`)을 가집니다.

### 자막
- 최대 3줄. 시작·끝 시간은 따로 정하지 않고, 줄이 여러 개면 그 장면 시간을 똑같이 나눠 순서대로 보여 줍니다.
- 자막 모양은 영상 전체에 하나: 번들 글씨체 35종, 글자색 15개, 위치(위·중앙·아래 + 직접 끌기), 크기(작게·보통·크게), 배경, 등장 효과.
- "뒤 장면에도 넣기"로 같은 자막을 복사합니다.

### 스티커
- 이모지 20종, 장면당 3개까지.
- 붙이면 바로 위 미리보기에서 손가락으로 끌어 옮길 수 있고, 두 손가락으로 크기를 조절합니다(0.4~3.5배). 크기 버튼(작게·보통·크게)을 누르면 손으로 바꾼 배율이 지워집니다.

### 배속·장소 라벨·끝 화면

- 이어 재생에서 영상 원본 구간을 0.5·1·1.5·2배속으로 구성합니다. 타임라인 길이는 사용 구간을 배속으로 나눈 값입니다. 분할에서는 배속을 제공하지 않습니다.
- 장소·날짜 라벨은 켜고 끄는 값을 장면별로 보관합니다. 위치·모양·등장 효과는 영상 전체에 적용합니다.
- 전체 구성에서 끝 화면을 켜면 마지막에 문구를 2초간 표시합니다. 빈 문구의 기본값은 `함께한 날들`입니다.

### 소리(702ba0c)

- 전체 구성에서 원음 유지(기본) 또는 음소거를 선택합니다.
- BGM 없음 또는 예시 음악 20곡을 분위기 탭(잔잔·산뜻·감성·신나는·귀여운, 탭마다 4곡)에서 골라 ▶로 들어 보고 음량(작게·보통·크게)을 조절합니다. 선택한 BGM은 전체 미리보기에서 재생합니다. 원음은 미리보기에서 나지 않습니다.
- 예시 곡은 `scripts/make_example_music.py`로 직접 합성한 시연용 음원(CC0)이며 `assets/music/`에 약 11MB입니다. 서비스에서는 사용권이 확인된 음원이 필요합니다.
- 프로토타입 어댑터에는 `originalSound`와 `music{id,volume}`이 전달됩니다. 제품의 확정 정책은 원음 유지와 BGM 없음입니다. 최신 프로토타입의 렌더·갤러리 handler는 미등록 상태입니다.

### 동영상 재생
- 동영상 칸에 **실제 파일이 있으면** 표지 사진 대신 영상을 소리 없이 반복 재생합니다(쓰는 구간 시작·재생 속도 반영, 미리보기를 멈추면 같이 멈춤). 둥근 ▶ 표시는 없앴습니다.
- 파일이 없는 기록은 표지 사진으로만 보입니다. 프로토타입의 브이로그 예시 동영상 6곳에는 앱에 들어 있는 예시 영상(카페·숲)을 연결했습니다.

### 전체 구성 화면의 설정 창
- 제목·소리·음악은 길게 펼치지 않고 한 줄 버튼으로 두고, 누르면 설정 창(아래에서 올라옴)이 열립니다.
- **제목 화면** 창: 날짜마다 한 줄(날짜 · 제목 입력 · 켜기), 모양 12가지(옆으로 넘김), 머무는 시간 1~5초(기본 2초, 끝 화면은 2초 고정).
  - 모양: 기본, 액자, 큰 숫자, 폴라로이드, 티켓, 반반, 필름, 포스터, 네온, 스탬프, 파스텔, 심플. 날짜 번호("DAY 2")와 요일이 들어가고 끝 화면에도 같은 모양이 적용됩니다.
- **소리·배경 음악** 창: 위 "소리" 절의 선택지를 한 창에 모았습니다.

### 전체 미리보기
- 위쪽 "수정"과 아래쪽 "자막·장면 수정"은 지금 보고 있는 장면의 장소 편집 화면으로 이동합니다(제목·끝 화면이면 그날 첫 장소, 없으면 전체 구성). 영상 제목은 전체 구성 화면에서 고칩니다.

### 달력·내 모임 (UI 정리)
- 전체 일정 달력: 위에 모임별 필터 알약("모든 모임" + 모임들), 모임을 고르면 그 모임의 가장 가까운 일정이 있는 달·날짜로 이동, 카드를 누르면 모임방이 아니라 그 일정(그날 장소 목록)으로 이동, "이 달 N개" 배지는 없앰.
- 내 모임 카드: 일정 요약(진행 중·다음·최근 일정)과 보관 안내 띠를 뺐습니다. 문구는 "N명이 함께 기록하고 있어요", 나 혼자면 "추억을 차곡차곡 모으고 있어요". 모임 안 위쪽 인원은 "N명"으로 통일했습니다. 보관 만료 안내를 어디서 알릴지는 정해야 합니다.

### 길이 기본값
- 사진 한 장은 이어 재생·분할 모두 기본 3초입니다(직접 1~10초).

### 기본 설정으로 바로 만들기
- 장소 선택 화면과 사진·동영상 선택 화면의 "⚡ 기본 설정으로 바로 만들기" 버튼.
- 아직 고르지 않은 장소는 앞에서 5개씩 담고, 장소 설정은 이어 재생·편집 완료로 처리합니다. 영상 전체 설정이 비어 있으면 전환 페이드·사진 움직임 천천히 확대·날짜 제목 화면·끝 화면을 넣습니다. 이미 정한 값은 유지합니다. 전체 180초·50개 한도를 넘으면 넘는 기록은 담지 않고 알립니다. 완료 후 전체 미리보기로 이동합니다.
- 기본값은 `src/prototype/vlog/quick.ts`의 `QUICK_DEFAULTS`입니다. 사용자가 기본값을 직접 정하는 화면은 아직 없습니다.

## 2 결정 메모 — 수동 조절이 되면 별도 버튼은 줄인다

의견(사용자): 자막·이모티콘의 위치와 크기를 손으로 조절할 수 있는 것이 앱에서 확인되면, 화면 편집에 위치·크기 버튼이 따로 없어도 된다.

| 항목 | 프로토타입 현재 | 앱에서 확인 |
| --- | --- | --- |
| 자막 위치 | 버튼(위·중앙·아래) + "직접 옮기기"(미리보기에서 끌기) | 앱에서 자막을 손으로 끌어 위치를 정할 수 있는지 |
| 자막 크기 | 버튼(작게·보통·크게)만 있음. 손가락 확대·축소는 없음 | 앱에서 손가락으로 크기를 바꿀 수 있는지 |
| 스티커 위치 | 미리보기에서 끌기(위치 버튼은 뺐음) | 앱에서 끌어 옮길 수 있는지 |
| 스티커 크기 | 두 손가락 확대·축소 + 버튼(작게·보통·크게) | 앱에서 두 손가락으로 조절되는지 |

- 앱에서 확인되면: 자막의 위치·크기 버튼 줄을 화면 편집에서 빼도 됩니다(손으로 하는 방식 하나로 정리).
- 앱에서 안 되면: 프로토타입의 버튼을 그대로 두거나, 손 조절을 앱에도 추가하도록 요청합니다.
- 프로토타입 웹은 마우스라 두 손가락 동작을 확인할 수 없습니다. 이 항목은 폰에서 확인해야 합니다.

## 3 결정 메모 — 칸 배치 순서를 끌어서 바꾸기 (미구현)

의견(사용자): 분할 템플릿에서 위 칸 사진을 아래 칸 사진 쪽으로 손가락으로 끌면 서로 바뀌도록 되어야 한다.

- 현재 프로토타입: 칸 순서는 "칸 배치 편집" 시트의 위·아래 버튼으로만 바꿉니다. 사진을 칸 위에서 끌어 바꾸는 동작은 **없습니다**(미구현).
- 앱에서 확인: 분할(2~5칸) 화면에서 한 칸의 사진을 다른 칸으로 끌어 놓으면 두 사진의 자리가 바뀌는지.
- 구현 시 정할 것: 끌 때 어느 칸 위에 놓는지 표시, 놓으면 두 칸의 사진·크기 설정이 같이 바뀌는지(칸 모양은 그대로), 이어 재생에서는 장면 그림 줄을 끌어 순서를 바꿀지.
- 순서가 바뀌면 재생 순서·칸 번호·"뒤 장면에도 넣기" 대상도 함께 바뀌므로 규칙을 같이 정해야 합니다.

## 4 앱에서 확인할 목록

1. 자막을 손으로 끌어 위치를 정할 수 있는가, 손가락으로 크기를 바꿀 수 있는가.
2. 스티커를 끌어 옮기고 두 손가락으로 크기를 바꿀 수 있는가.
3. 분할 화면에서 사진을 다른 칸으로 끌어 서로 바꿀 수 있는가.
4. 색감·전환·사진 움직임·템플릿(폴라로이드 기울기·테두리·검은 바탕)이 영상 생성 결과에 반영되는가(프로토타입은 미리보기용).
5. 자막이 여러 줄일 때 장면 시간에 균등하게 나뉘어 나오는가.
6. 폰에서 올린 실제 동영상이 미리보기에서 재생되는가(여러 칸 동시 재생의 성능 포함).
7. 제목 화면 12가지 모양이 영상 결과에 그대로 나오는가.

## 5 서버 렌더러(backend)에 전달할 값

프로토타입 확장값 목록입니다. 제품 채택 시 렌더 계약과 미리보기·출력 일치 여부를 함께 검증합니다.

- 색감 ID 10개 추가: warm, cool, film, vintage, vivid, fade, cinema, noir, dream, sunset
- 전환 ID 5개 추가: blur, spin, pop, wipe, iris
- 템플릿 ID와 칸 정보 63개: 기울기 `rots`(도), 테두리 `look`, 바탕색 `bg`
- 스티커: 손으로 놓은 위치 `xy`(0~1 비율)와 배율 `scale`. 가장 가까운 3×3 자리 이름(`spot`)도 함께 저장합니다.
- 자막 글자색: 이름 대신 `#RRGGBB` 값으로 전달하는 방식을 권장합니다(15색).
- 자막 시간: 줄별 시작·끝을 저장하지 않고 줄 수로 균등 분할합니다.
- 사진 기본 길이 3초(이어 재생·분할 공통).

- 배속 `speed`, 끝 화면 `endCard`·문구, 장소 라벨 설정, 오디오 `originalSound`·`music`.
- 제목 화면: 모양 ID 12개(`titleStyle`), 머무는 시간 `titleCardSec`(1~5초), 장면의 `titleDay`(몇 번째 날)·`titleWeekday`(요일)·`titleImage`(그날 첫 사진). 끝 화면은 같은 모양에 날짜 없이 2초.

## 6 기존 결함과 실행 근거

- VB01은 최신 코드의 생성 버튼에서 장소 완료·유효 원본을 재검사합니다.
- VB02는 분할 길이를 늘릴 때 시작점을 자동 보정하지 않습니다. 원본보다 긴 구간은 미리보기·생성 진입 검사에서 차단합니다.
- 작성 시점의 제품·프로토타입 실행 범위는 [11월 27일 Android 15 검수](../검수/2026-11-27_Android15/README.md)에 기록합니다.
