# 정책 기준 사본 안내

`기능명세서.md`는 정책 원본과 SHA256이 같은 사본입니다. 본문 상대 링크도 원문 그대로이므로 **정책 원본의 위치(`docs/기능 명세서/`) 기준**입니다. 이 폴더에서 읽을 때는 아래 링크를 사용합니다.

- [이전 프로토타입 대조](../10%20프로토타입%20대조%20보완.md)
- [브이로그 설계](../11%20브이로그%20제작%20설계.md)

- [미설계 화면 처리 의견](../../회의록/2026-11-01_앱_점검_캡처/미설계_화면/2026-11-10_미설계_화면_처리_방향.md)

설계서만 독립 복사한 패키지에는 외부 QA·회의 원문이 없을 수 있습니다. 패키지 내부의 12번 설계에서 출처·요약·검수 기준을 확인합니다. 링크 경로만 바꾸기 위해 기준 사본을 수정하면 SHA256 일치 검증이 실패합니다.
